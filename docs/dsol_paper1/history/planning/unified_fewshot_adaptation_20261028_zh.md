# 统一少量交互适配：跨操作模型与部署场景

2026-10-28，北京时间。用户已选择FastWAM并要求把跨模型迁移和真机少训一起设计/验证。本轮实现CPU候选并验证实际PPO入口，未启动新模型训练、推理、仿真、真实头部或W&B。下面的新科学验证面板尚无执行许可，不沿用旧期限/预算。

## 目标与模型来源

目标是仿真中训练一次兼容的搜索策略，新模型/新部署域首先直接推理；需要学习时，复用源actor、用有限目标正式交互适配。不是要求每次部署从零训练2048回合。FastWAM是操作模型，[FluxVLA](https://github.com/FluxVLA/FluxVLA)是集成包括FastWAM在内的多个模型的工程框架；我们的LIBERO优先核验[FastWAM作者路线](https://github.com/yuantianyuan01/FastWAM)，GR1候选目前来自FluxVLA，分别冻结版本。不能把两个名称视为同一模型或把两个实现的成绩混用。

共通的是搜索actor、合法相机动作、评分/查询成本及PPO适配流程；不同的是操作模型视觉接口、评分地形以及真机传感/运动误差。G只有reward的在线尺度，不能自动修正全部域差异。跨模型和真机少训可以联合研究，但仿真迁移成功不等于真机已通过。

## 第一版明确算法（候选，区别于已发表结果G）

保留连续yaw/pitch增量、STOP、历史网络、最多8查询、两条评分噪声、成本0.01与最低Accel选位。先不加入L、BO、强制探索或任务成功监督。使用共同固定视觉编码器；LIBERO先提取现有π0.5 SigLIP视觉塔并核验预处理、2×2池化、视图顺序和4608维特征。独立视觉桥仍未实现/验收，不能直接换成FastWAM自身特征或补零冒充兼容。

1. **新域显式建档。** `domain_sha256`由操作权重、评分定义、噪声协议、视觉编码器、传感器/安装/环境绑定构成。源actor可以继承，目标reward统计从空开始，建立新optimizer和critic；源统计不拼入目标窗口。正常resume恢复本域原状态，不重新计费。域变化是显式绑定事件，不是假设有自动漂移检测。
2. **每8个完整正式回合更新一次。** 先收集原始改善量和查询次数，第一批也用于学习，不是额外校准。只从初始查询得到a_i（两成员均值）与d_i（两成员标准差），保留最近32个初始查询。低Accel候选不决定自己的奖励分母。
3. **稳健目标尺度。** m_k=median(a_i)，n_k=Q75(d_i)，目标s_target=max(m_k,2n_k)。首批采用该值；之后将变化限制在上一批尺度的[1/2,2]之间。整个批次使用同一s_k，GAE和PPO优化中固定。r=(best_before−best_after)/s_k−0.01ΔQ；初始观察与返回查询仍按原协议计费。
4. **保持原输入契约。** 不把新reward分母偷偷代入预训练actor的分数输入。零样本输入尺度OOD仍可能存在，由直接迁移和少量学习对照检验。若另改输入归一化，必须新版本及源域兼容验证，不能称纯reward修改。
5. **零训练部署与少量适配分开。** 冻结actor推理无需计算reward或先凑8回合。需要更新才采集8回合一批；第一轮验证0/8/32/64目标回合。不承诺8回合就有效，达到预算仍无收益则停止这一轮，不自动扩成2048。

2n_k是评分成员分歧启发式，不能代表真实相机噪声置信界；步间限幅后也不保证分母始终高于本批2n_k。这个项降低部分不稳定低分的激励，但不能保证低Accel就是好操作。全零/非有限尺度停止更新，不添加任意epsilon制造超大奖励。窗口、8回合批次、系数2都是本版需验证的固定参数，不宣称已最优。

与旧G相比，本版显式处理新域统计隔离、短窗口与小批量；这些是算法协议变化，所以旧G的77.78%不重新命名成本版结果。与此前“32回合/128回合迁移”草案相比，本轮将其收敛到统一8回合批、64回合端点，避免每个问题再新增一套庞大实验。

## 联合验证：两个轴、四个条件

首轮两个域：π0.5→FastWAM的同LIBERO模型变化；π0.5在预先固定安装变化条件下的部署域变化。第二项只验证部分几何域变化，不当作真实外观、光照、遮挡和相机噪声的替代。安装条件复用已验证运动学，不改URDF。跨本体GR1/Bot2还需合法头部几何和视图契约；若无腕部相机，不得随意补零向旧actor输入，须建立有正确视图mask且在仿真训练过的源策略。

| 初始化 | 尺度方案 | 用途 |
| --- | --- | --- |
| 源G actor | 首批8回合估计后固定 | 迁移但不持续自适应 |
| 源G actor | 本版短窗口在线更新 | 联合候选 |
| 随机actor | 首批8回合估计后固定 | 同预算从零对照 |
| 随机actor | 本版短窗口在线更新 | 分离在线尺度与源知识 |

四组共同固定视觉塔、PPO设置、批大小、目标训练任务/初态和查询预算，使用相同critic初始化规则；每组3种子、各64回合，记录8/32/64端点。新域先只改变是否迁移actor和是否更新尺度，不同时新增KL控制、小头冻结或新观测归一化。首批固定组也使用同样分歧启发式，这个对照不是历史B；历史B/G完整表继续保留。第一批两种尺度模式应严格同轨/同参数，否则停止检查，不能直接归因于统计波动。

每域预留768训练回合（4×3×64），最多12,288评分调用。开发验证使用8任务×2独立初态×2预定扰动起点、两操作噪声；不筛成功任务。端点含源策略0回合、两种初始化的8回合（尺度两组首批逐值相同后才复用），四组32/64回合，共33个策略端点，2,112操作。参考/保持/局部/随机候选共224操作；若机械零等于参考不重复充当独立证据。每域共2,336操作、17,920搜索评分上限；两域合计1,536训练回合、4,672操作、60,416训练/搜索评分调用上限。操作生成调用及工程验收需按目标checkpoint/chunk和时限补齐，不能用此评分上限当总预算启动。源训练成本、独立视觉编码时间也单列。

小面板用于开发决策，成功不能包装成完整跨任务迁移结论。方案/端点根据开发结果选定后，完整12个PPO未见任务做冻结确认，并保留不调整、已知参考、机械回零可区分条件、局部与随机。若要声称64回合等效2048回合，必须有目标模型相应参考与预定非劣效界限；只胜过随机64回合不足以证明。

主指标为操作成功率、净救回、损害、模型调用、头部移动和真实用时。预先选损害容忍界限并以任务配对区间判定；预算耗尽/区间不足不自动加样本。不能以reward更高、查询更多、归一化更稳定代替操作效果，也不隐藏负结果。

## 真机时间与实施顺序

64次搜索回合每回合最多8查询，最多512个计费观察点、1024条评分生成轨迹；多数搜索训练不需要执行完整机械臂操作，但头部移动/稳定/拍摄/布置场景仍耗时。真实成功率验收必须执行操作，不能省掉。

可审计时间公式：T适配≈Q×(头部移动稳定拍摄时间+两条评分总耗时+独立视觉编码耗时)+场景准备+CPU更新。仅作例子：若每查询端到端3–6秒，512查询约26–51分钟，尚不含布置和操作验收；这不是目前硬件实测或承诺。零适配、8回合、32回合与64回合要画效果—真实时间曲线，才回答用户“不训得天荒地老”的要求。

步骤：完成CPU入口/恢复验证；接FastWAM资产与独立视觉桥，验证只读trace和原生动作一致；冻结小面板和总预算后做联合仿真；按结果确定少样本预算；再在有正确相机/运动学的真机上做有限场景验证。可并行准备真机标定和场景清单，但不把LIBERO actor零样本上Bot2写成已具备能力。整批先不用多个新模型扩张，FastWAM一条迁移边成立后再扩大模型覆盖。

## 本轮实现及已验证边界

新增`data/adaptation_reward.py`，纯CPU、不可变原始输入、域/协议绑定、8回合屏障、32窗口、首批固定/在线对照、显式零尺度拒绝。`selectors/continuous_ppo.py`按独立schema在GAE前结算，并在checkpoint/resume恢复窗口和累计计数；原B/G/L函数字节不变。新增actor-only初始化接口，只复制actor并保持新critic，不加载旧optimizer/RNG/尺度，也不宣称该函数能自动对齐特征。

数据单测29项（含旧在线reward）通过。Fresh现有RL环境关闭GPU可见性，用合成后端运行实际PPO入口：初版33项通过，覆盖完整8回合更新、窗口淘汰后精确恢复、失败禁止重放、旧完整warm_start拒绝以及旧B/G/L恢复。新增actor-only测试后最终入口回归6项通过（8.09秒），结果见持久日志。center portable初版697通过/36跳过；Torch类跳过单列，不能称center已执行Torch测试。

**仍未完成**：独立视觉塔的数值验收、FastWAM运行与Accel适配、生产32回合清单/采样器的显式新协议接入、真实小面板，以及真机标定/准入。通用CPU PPO支持8回合不等于生产分布式入口已接通，旧生产入口仍拒绝本候选；不绕过旧检查直接启动。
