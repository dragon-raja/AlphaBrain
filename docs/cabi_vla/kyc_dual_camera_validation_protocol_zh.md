# Pi0.5 双相机 KYC 最终验证协议

## 研究问题

在外部相机与腕部相机同时存在的 Pi0.5 策略中，显式相机几何是否仍能提高跨位姿、跨背景任务泛化？增益来自外部相机、动态腕部相机，还是二者的一致几何坐标系？

## 核心改动

- 外部相机使用当前真实内外参生成 Plucker ray map。
- 腕部相机按每个策略推理时刻读取动态内外参。
- 两个视角共享同一射线编码器，保证对照组参数量一致。
- 使用零门控残差融合；初始化时严格保持 Pi0.5 RGB token 不变。
- 几何只作为当前观测输入，不使用未来状态、任务标签或成功信息。

## 五组训练对照

| 组别 | 外部相机 ray | 腕部相机 ray | 作用 |
|---|---|---|---|
| RGB | 无 | 无 | 原始容量基线 |
| Dual-Control | 固定规范位姿 | 固定规范位姿 | 等参数几何分支基线 |
| External-KYC | 实时真实位姿 | 固定规范位姿 | 外部相机几何主效应 |
| Wrist-KYC | 固定规范位姿 | 实时真实位姿 | 腕部动态几何主效应 |
| Dual-KYC | 实时真实位姿 | 实时真实位姿 | 联合效果与交互效应 |

所有组固定 Pi0.5 初始化、随机视角训练窗口、数据顺序、优化器、冻结模块、33K 更新、seed 41/42/43 和执行 K。

## 数据与评测

1. **内部机制门控**：LIBERO-Bind 随机外部视角，方位角 ±60°、俯仰偏移 ±25°、距离比例 0.90–1.25。
2. **背景干预评测**：隐藏或随机化房间固定视觉线索，避免仅凭桌面与背景反推相机位姿。
3. **LIBERO-Plus OOD**：审计官方资源后固定使用其相机参数与场景变化，不根据结果挑选子集。
4. **因果射线干预**：RGB 不变，腕部 ray 分别使用正确、初始固定和滞后一时刻外参。

## 指标与统计

- 主指标：闭环任务成功率、各相机轴成功率曲线、严格全可见子集成功率。
- 辅助指标：抓取、抬升、搬运、放置子目标；目标出视野边界；完成步数。
- 统计单位：`任务边 × 初始状态`，同组配对 bootstrap 95% CI，逐 seed 报告。
- 交互效应：`Dual - External - Wrist + Control`。

## 裁决规则

- **支持双相机 KYC**：Dual-KYC 相对 Dual-Control 的 OOD 成功率稳定提高，且正确 ray 优于初始/滞后 ray；正常视角退化不超过 5 个百分点。
- **仅支持单视角几何**：External-KYC 或 Wrist-KYC 稳定贡献主要增益，Dual 无额外收益。
- **否定显式几何价值**：等参数 Control 与各 KYC 组无稳定闭环差异，或错误 ray 不改变行为。
- **实验无效**：RGB 与 Control 均不能学习基本任务，或数据可见性/相机标定门控失败。
