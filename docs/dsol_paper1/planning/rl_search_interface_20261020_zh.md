# Accel 引导的有限预算搜索：第一版接口与准入

状态：2026-10-20 已完成缓存接口与数据核验；未训练、未推理、未渲染、未执行新动作。
本页不修改历史协议，也不构成训练启动指令。当前报告不更新。

## 先验证什么

先用 LIBERO 已有外部相机候选，回答：在相同查询预算内，学习搜索能否比固定扫描、
随机搜索和局部 Accel 搜索更快找到有用视角。操作模型冻结，Accel 公式不改，
训练对象只是新增的搜索策略及其价值网络。

97 候选是一个规范视角加 96 个外部相机扰动，不是 97 种干扰类别。
保持扰动后原位不动的成绩，就是该初态、该起始候选、该操作模型对应的历史完整任务成绩。
搜索后的成绩从同一初态和模型、被选候选的同一套 32 次执行噪声记录读取。
搜索前后差值可以配对，但只代表静态端点重放，不包含真实移动相机对物理状态的影响。

这一阶段没有虚拟头部。后续头部适配须用颈部运动学生成可达相机位姿，重新核验图像与操作模型；
不能把旧 97 个外部位姿改名为头部动作，也不能把不同位姿的旧标签直接挪过去。
LIBERO-Plus 的其他干扰、原生人形 benchmark、自己的机器人分别属于后续适配。

## 数据与权限

输入适配器为 `AlphaBrain/research/dsol/data/search_replay.py`。
读取已有 INITIAL32 审计产物的 `matrix.npz`、`embeddings.npz`、`states.json`，
逐文件核对历史 `provenance.json` 的 SHA256，并在本次验证结束时复查。
路径由命令行传入；不改路径映射、历史文件或运行环境。

| 项目 | 第一版定义 |
| --- | --- |
| 原始数据 | 2 个操作模型 × 32 初态 × 97 候选 × 32 执行重复，共 198,656 条已有成绩 |
| 评分 | 同一初态每候选 8 套噪声 Accel；均值选位，标准差作为观测信息 |
| 图像 | 已缓存、冻结 ResNet18 的外部图像 512 维特征与腕部图像 512 维特征；不重新编码 |
| 开发/评价 | 8 个已知任务；每任务初态 0/1 开发、2/3 评价，各 16 初态 |
| 输入归一化 | 图像特征逐向量 L2 归一化；Accel 除以该模型开发集平均分数的中位数 |
| 缺失标签 | 通用评价侧保留 NaN 与有效配对次数；此特定历史矩阵要求完整，不将缺失补为失败 |
| 不提供给策略/critic | 成功标签、可见性分割、规范图像、候选名称、任务编号、未访问图像/评分 |

原 `context` 特征的前 512 维是规范外部图像，明确丢弃，只取腕部图像部分。
已知候选的相对位姿可以用于导航；不提供“返回规范相机”的专用动作。
97 候选是已知目录，后续训练可采集其中任意可达候选。评价起点 65–96 只是旧目录里的
heldout 起点组，不表示这些候选在训练搜索期间从未被访问。
整个同一物理初态只能属于一个划分，不能按起始视角随机拆分。
评价集此前已经分析过，本轮是开发证据，不能声称独立盲测或新任务泛化。

## 环境契约

核心为 `AlphaBrain/research/dsol/acquisition/search_env.py`，只依赖 NumPy。
`reset(start=...)` 读取一次起点观测并计入查询预算；`step(action)` 返回
`observation, reward, terminated, truncated, info`。
初态查询是不可选择避免的固定成本，记账但不进入动作奖励。

| 元素 | 定义 |
| --- | --- |
| 观测 | 相对起点的候选位姿、已查询特征和分数、访问顺序、当前位置/当前最佳标志、腕部特征、预算与累计移动量 |
| 隐藏信息 | 未访问点的图像和分数全置零，并由访问标志区分“未知”和真实零值 |
| 动作 | 0 为停止；1–97 为访问对应候选。仅允许已访问集合边界上的新候选；Gym 桥接每 episode 打乱槽位并同步重排观测/掩码，避免背下“0 号候选是规范相机” |
| 导航 | 沿已访问节点到边界父节点，再进入目标；经过已访问节点不重复评分 |
| 候选图 | 复用对称 6 近邻图；距离为平移/0.1 米 + 转角/15 度 |
| 停止 | 策略显式停止或用完预算，均返回已查询点中平均 Accel 最低的位置；平分保留先访问者 |
| 失败 | 非法动作拒绝且不改变状态；查询响应无效则该 episode 停止，不自动重试 |
| 预算结束 | 属于有限时域终止 `terminated=True`，不作为可继续自举的时间截断 |
| 记账 | 分别记录候选查询数、评分噪声成员数、访问与返回路径、米数、角度和奖励各项 |

访问动作是一个导航宏动作，不是每次电机控制步。所有方法使用相同合法动作集合。
环境只持有 `QuerySource`，不持有 `OutcomeTable`；后者仅在搜索结束后用于评价。
本地缓存的 8 个评分成员不是 8 次新增模型调用；真实在线接入时必须按成员数计推理成本。
相机移动量是几何代理，不是已测真实时间、碰撞可达性或能耗。

## 奖励与价值网络

设 b_t 为已访问候选的最低平均 Accel，s 为开发集确定的尺度：

`r_t = (b_t - b_(t+1)) / s - 0.01 × 新查询数 - 0.001 × 本步移动距离单位`

终止时返回最佳位置的移动也计入当前奖励。STOP 不额外获得“成功奖励”。
只奖励刷新最佳分数，不能靠分数先升后降、循环访问刷奖励。完整回报应逐值等于：

`(起点 Accel - 最终最佳 Accel) / s - 0.01 × 后续查询数 - 0.001 × 总移动量`

0.01 和 0.001 是第一版明确登记的工程成本，不是从成功标签拟合的权重，
也不代表已标定的真实时间成本。此次不搜索权重；若后续按硬件时延改成本，另立协议。
成功率不进入奖励，因此训练后仍可能偏好低 Accel 的失败视角，必须保留此负结果。

拟采用带合法动作掩码的 PPO。普通 PPO 不会自动遵守边界动作；适配器提供 `action_masks()`，
训练和评价都必须传递掩码，不能以“非法动作作为负奖励”替换当前契约。
可选 `gymnasium_env()` 桥接不在导入/构造时查询数据；缺少依赖时不自动安装。
官方文档：https://sb3-contrib.readthedocs.io/en/master/modules/ppo_mask.html

第一轮拟用标准字典观测展开 + 两层 128 单元 MLP 的 actor/critic 作可运行基线，
不是拟议论文创新，也不声称候选数量或排列泛化。输入中已保存全部访问历史，
不需要先引入循环网络。后续若固定目录基线值得保留，再改成共享候选编码器与集合汇聚，
避免把固定目录编号记成答案。这个结构变化必须在独立对照里说明。

- actor：给合法访问动作与 STOP 分配概率。
- critic：用同样可见信息预测剩余搜索回报，不预测机器人成功率，不看全候选隐藏分数。
- 操作 policy：原 VLA 完全冻结；图像编码器也冻结。新增搜索 policy 和 critic 才训练。
- 整套系统以后包含学习搜索，不能整体声称 training-free；Accel 本身仍不需训练。

本轮没有新增 actor/critic 实现、训练循环或依赖安装；先验收环境与数据契约。

## 简单对照与历史一致性

已接入不换位、按相对位姿固定顺序扫描、随机边界搜索、局部 Accel 搜索。
随机对照沿用历史“均匀抽边界边”的定义，不偷偷改成均匀抽唯一节点。
所有搜索对照最终都用最低 Accel 选位，起点计一次查询。

新环境用最短已访问路径到新候选；历史搜索的导航父节点选择规则不同。
因此，原局部搜索访问顺序、最终选择和历史成功率必须一致，但不要求移动路径与历史一致。
RL 和本轮简单对照的移动成本统一用新路径定义，不能拿新路径成本和旧路径成本直接比快慢。

接口核验覆盖两模型全部 32 初态、起点 65、预算 4/8/16、4 个对照：
768 个缓存接口 episode。对 16 个评价初态的局部 Accel 对照进行 96 组历史黄金比较。
这些是程序验证，并非 768 次新机器人实验，也不是 RL 效果评测。

本次持久化回执（最后接口版本）：
`/share/personal/longjunyu/alphabrain/experiments/rl-search-interface-20261020/admission-final/receipt.json`。
先前 `admission/` 保留补充动作槽位随机化前的验证，不覆盖原回执。
输出目录必须不存在；失败单独写原因后停止；不修改历史 latest 指针。

最终验证：获取模块与新增数据测试 122 passed、101 subtests passed、2 skipped
（其中一个为本环境未安装 Gymnasium 的可选桥接测试）；仓库 portable 测试 112 passed。
仓库静态检查、架构检查、布局检查与 staged 内容检查通过。Gymnasium、Stable-Baselines3、
sb3-contrib 均未安装，因此不宣称训练库适配已实际运行。

## 拟议最小训练预算（尚未启动）

| 阶段 | 预算 | 目的 |
| --- | --- | --- |
| 训练接口 smoke | 1 seed × 2,048 个搜索决策步 | 验证掩码、梯度、checkpoint 重放；权重丢弃，不选最好结果 |
| 第一轮方法试验 | canonical 操作模型，3 seeds × 32,768 决策步 | 固定参数，不扫权重、不按评价成绩选 checkpoint |
| 总训练上限 | 100,352 决策步 | 全部在旧缓存上；新增 VLA 调用、物理 rollout、渲染均为 0 |
| 主预算 | 每 episode 最多 8 次候选查询，含起点 | 训练与主评价一致 |
| 训练分布 | 16 开发初态等权，起点 1–64 等权 | 不混入评价初态 |
| 主评价 | 16 评价初态 × 32 起点 × 3 seeds = 1,536 搜索 episode | 使用每 seed 最终 checkpoint，确定性选动作 |
| 辅助预算 | 4 与 16；三预算合计 4,608 个 RL 缓存评价 episode | 标为预算变化诊断，不当作训练覆盖范围 |

不用新任务筛掉负例；缓存训练成本很低，第一轮直接保留原 8 任务，而非事后挑两个有利任务。
原 broad 操作模型数据已验证，但第一轮不另训第二套 RL；跨模型测试另列，
不能借每个模型重训后成绩声称零成本迁移。

拟定训练参数：CPU、16 个顺序向量环境（每开发初态一个，不创建 GPU worker），
每环境 64 步组成 1,024 步更新批次；batch_size=64，n_epochs=4，
learning_rate=3e-4，gamma=1.0，gae_lambda=0.95，clip_range=0.2，
ent_coef=0.01，vf_coef=0.5，max_grad_norm=0.5；正式 seeds=0/1/2，smoke seed=17。
gamma=1 对应有限搜索总成本目标；不以折扣偷偷改变终点目标。
这些是待训练准入的方案，不是本次已运行配置。
训练吞吐未实测，暂不给 GPU 小时或墙钟完成时间承诺。

开始训练前还需在独立环境完成 Gymnasium/MaskablePPO 兼容核验、跨初态采样器、
初始化/重载与带掩码评价测试；不修改已有模型/仿真环境。训练启动需后续明确指令。

必须同时报告成功率、相对保持原位的挽救/伤害比例、查询次数、几何移动成本、最优已访问 Accel。
查询预算相同不代表实际查询次数相同；RL 提前停止需另报查询数和成功率—查询数曲线。
先在每个初态内平均起点与搜索 seed，再做配对比较；不能把起点当独立物理初态。
如果只降 Accel 不改善任务，或简单局部搜索已经同样好，均保留，不能靠改奖励追成绩。

## 后续接口扩展

`QuerySource` 可替换为在线“到达相机位姿后渲染+冻结模型评分”后端；
候选目录可换为颈部可达姿态图，但还需实际运动执行和时间成本接口，不能只换几张图。
缓存中的静态不动假设将失效，必须单独做动态验收。
多窗口更适合随后加入“执行一段后何时重新搜索”的决策；不能把每个候选的未来动作分支
当成真机上免费可得信息。当前接口明确没有多窗口分支执行。
