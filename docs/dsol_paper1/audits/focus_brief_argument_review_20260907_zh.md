# VLA视角利用研究：论证与表述审查

日期：2026-09-07。对象：10页研究汇报。未改变实验配置、原始结果或科学评测。

## 总体判断

目前的页序可以构成论文研究进展的论证骨架：训练覆盖与性能权衡 → 条件视角价值 → 选择可预测性 → 训练交互与观测获取的验证设计。它不是已经完成全部核心贡献的论文，也不是所有既往实验的清单。

“可用于论文”需要区分：正文中的基准与对照证据、机制线索、方法基线、附录中的协议审计，以及尚未执行的研究设计。旧结果可复用，不意味着其支持的主张可以扩大。

## 各页的论证职责

| 页 | 论文中的可能位置 | 可支持的内容 | 不支持的外推 |
|---|---|---|---|

| 2 | 开发对照 / 强基线选择 | 外部多视角后训练改善已测未见位姿的被动鲁棒性；配对与一致性未证实额外收益 | 单seed、24状态推广为所有VLA的规律；将未证实增益当成方法无效或腕部捷径的证明 |
| 3 | 基准结果 | 当前宽视角后训练方案的Camera/Original性能权衡 | 将相对冻结参考的全部改善单独归因于覆盖；将整套一致性方案差异当成独立损失效应 |
| 4 | 机制线索与竞争解释 | 信息视角在特定状态集上有正向结果；可见性与训练位姿熟悉度尚未被当前设计分离 | 跨不同状态集直接相减；零差值视为等效；将像素占比直接解释为任务信息量 |
| 5 | 有限预算离线搜索诊断 | 部分状态候选有正向点值；独立噪声下的整体程序收益尚未通过预设标准 | 将其称为候选域真实最优值、普遍稳定上限、免费可部署选择器或动态主动感知结果 |
| 6 | 条件搜索与学习基线 | 逐状态相对任务固定的事后对照；两种选择器的独立Q结果 | 因少数选择器失败断言无法学习；混淆两面板参考基线或候选图权限 |

| 8 | 与相关工作的关系 | 明确拟检验的训练依赖性与任务证据条件 | 将多视角、主动视觉或价值回归本身作为新增贡献 |

| 10 | 待验证方法原型 | 允许输入、配对收益监督、可行动作选择与保持阈值 | 把普通优势回归当成已完成算法创新或已成立的部署收益 |

## 主图必须保留的最小条件

- 输入和干预：外部、腕部图像与语言；静态相机位姿固定不等于图像固定；恢复状态评测不同于初态基准。
- 模型身份：Broad32开发模型、Broad64开发模型、Broad64正式M-B分别标注，不能串成同一checkpoint的改进曲线。
- 独立样本与随机性：训练seed、示范来源、状态、推理噪声分别计数；复用来源不能按新增独立场景计数。
- 统计口径：按episode汇总的成功率不同于任务/演示等权效应；不同CI实现不能合称为一个统一泛化区间。
- 选择权限：任务固定在开发集确定；离线状态搜索使用待评状态的闭环标签；候选图选择器额外读取候选图像。

## 既往五条结论的衔接审查（不投影）

本节供作者核对既往汇报口径，不作为PDF中的纠错页。正文保留“外部多视角后训练”“被动视角鲁棒性”“信息视角”“Accel初噪敏感”“局部候选收益”等已获支持的表达，同时标明实验范围和后续确认结果。

| 既往结论 | 本版采用的表述 | 需要作者掌握的差别 |
|---|---|---|
| 1. 外部多视角位姿后训练提升被动视觉鲁棒性 | 外部多视角后训练改善被动视角鲁棒性（第2–3页） | 将“视觉”限定为当前研究的外部位姿扰动；多视角是训练位姿多样化，不是同时增加多个外部输入。正式Camera相对冻结参考还包含后训练本身的影响，且Original存在性能损失。 |
| 2. 配对视角、一致性无明显效果，可能是diversity或腕部捷径 | 当前配对与一致性未证实额外增益（第2页） | 未证实不等于无效。小开发对照的独立损失差值区间跨零；正式组合配方还改变了数据组织和每步独立记录数。多样性与腕部捷径均未被因果对照确定。 |
| 3. 像素占比的信息视角可提高特定任务闭环成功率 | 信息视角在特定状态集上表现更好，但不能单独归因于可见性（第4页）；选择规则需另做复验（第7页） | 特定任务中的所测状态不等于完整任务分布。像素可见性是候选构造代理，不是任务信息量的定义；新来源门控复验为负，不支持一般性的像素选择规则。 |
| 4. Accel初噪敏感；加入信息视角判断可提升闭环 | Accel排序受初噪影响；混合规则正点值仍待验证（第7页） | Broad64 practical的六噪声Top1全同仅2/96状态，排名Spearman=0.412。混合规则83/96对规范81/96，+2.08pp，95%CI[−3.13,7.29]；不能称已证实提升，排名不稳也不自动等于行为无效。 |
| 5. 存在不少提高闭环成功率的候选，但没有稳定识别方式 | 部分状态观察到候选收益；整体收益与可预测性均需继续确认（第5–6页） | v2相对规范为7正6负3平的点值，整体+3.91pp、95%CI[0,7.81]，未通过预设标准。这些不是各状态显著性结论，亦未证明存在普遍稳定上限后仅剩学习器问题。有限方法失败不等于不存在识别方法。 |

### 相关工作措辞边界

- [LIBERO-Plus §6.2](https://arxiv.org/html/2510.13626v3#S6.SS2)和[RoVi-Aug](https://rovi-aug.github.io/)是视角多样化与鲁棒性的相关先例，不是本地Pi0.5双相机配置的直接实验依据。
- [CVC §4](https://arxiv.org/html/2608.06965v1#S4)在训练、评测均屏蔽腕部的协议中报告一致性收益。不能改述为“去掉腕部后才有效”：原论文没有腕部有无与一致性有无的交互对照，且训练配方也不同。第2页仅标其输入协议，不作原因归纳。
- [ActiveVLA §3](https://arxiv.org/html/2601.08325v1#S3.SS2)结合学习的关键区域定位、点云几何加权、虚拟重渲染与局部放大，不是单纯按整图目标像素比例排序，也不是实际相机移动。[LIBERO-Occ](https://arxiv.org/html/2606.10862v2#S2)研究目标相对遮挡比例及互补视图想象；遮挡比例不同于本地目标像素占整图比例。二者均为机制相关工作，不能为本地像素代理有效或稳定候选上限提供直接证明。
