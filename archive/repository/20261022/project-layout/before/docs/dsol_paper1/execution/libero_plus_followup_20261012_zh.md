## 对外部分析的采纳与修正

采纳三个分开的研究问题：是否存在配置恢复；逐初态适配是否超出开发集固定配置；部署可用信息能否获得这部分额外收益。拒绝把“多步选位未通过主比较”直接写成“Accel没有信号”或“个例差异不存在”。

1. LIBERO旧多视角模型的开发集全局Accel模板86.13%确实可核对，但它排除规范位、只用开发Accel，不是成功标签选出的最优固定位。86.52%的逐初态规则允许规范位；同为96非规范候选时该规则为88.09%。原分解可作为警示，不能把0.39pp当严格同权限自适应增益或等效证明。
2. 固定配置用完整任务标签选择后，是更强但监督不同的基线。本轮CPU探索中，开发初态0/1选任务固定配置，在初态2/3的非规范96目录上，规范模型88.67%、多视角模型91.21%；对应逐初态Accel为61.52%、88.09%。这些是已看过数据上的描述性比较，不是新独立确认，不能据此宣布学习到普适校准。
3. 把评分重复分成前4/后4，XR-1的W3平均逐初态Spearman为0.916，赢家一致率57.5%；π0.5的W5分别0.590和8.75%。排序大尺度可复现不等于极小点稳定；长窗口的重复差异还包含动作执行后的分支状态差异，不是纯初态单次推理噪声。
4. 固定基线强不证明个例收益不存在；噪声分半赢家的独立成绩不是无偏真实Oracle。重复少时，选位误差本身可能让这个特权选择器输给固定方案。
5. 当前多分支短执行后复位只是诊断信息权限，不是可部署低成本搜索。改成长时在线换视角需新问题定义和同中间状态分支数据，不自动并入本轮。
