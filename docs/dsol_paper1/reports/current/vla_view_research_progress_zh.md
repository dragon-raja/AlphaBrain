## 1. 已确定的主问题

从标准任务初态出发，在完整任务执行中固定一个外部相机位姿。比较不同候选视角的多噪声平均成功率，研究训练覆盖如何改变候选收益，以及指标或选择器能识别其中多少收益。

- 任务初态：环境正常任务开始的物理条件，不是任意抽取的演示中间帧。
- 任务结果：实际执行至完整任务目标成功或达到共同步数上限。
- 噪声重复：每套噪声对应一次完整闭环执行，包含过程中需要的推理噪声序列。
- 视角选择：每个初态先对噪声求平均，再取候选视角中的最高者。
- “非全局固定”：不同任务或不同初态可以选择不同视角；同一次执行内相机位姿不变。
- 不允许逐噪声事后替换赢家；不把动作重规划或腕部图像变化称为外部视角动态选择。

形式化定义：令 Y(x,v,r) 为从任务初态 x、固定候选视角 v、使用第 r 套噪声执行完整任务的成功指示。先计算 Ĵ(x,v)=mean_r Y(x,v,r)，再计算 v̂(x)=argmax_v Ĵ(x,v)。最后按预先规定的任务与初态权重汇总 max_v Ĵ(x,v)。

它不同于 mean_r max_v Y(x,v,r)：后者让赢家随噪声试验改变，不是本研究采用的 Oracle。

## 2. 三种结果不混用

1. 经验候选上限：在完整初态—视角—噪声矩阵中，比较规范、全局最佳固定、每任务最佳固定和逐初态经验 Oracle。需要共同初态、候选域、噪声及汇总权重。每任务最佳固定取该任务跨初态平均最高的候选；它与初态 Oracle 同属事后空间参照，不冒充开发期冻结的可部署基线。
2. 选定视角的独立复评：冻结选择后，用新噪声重新完整执行。检查平均收益能否保持，不在新结果上重选赢家。它估计冻结选择的表现，不是经验 Oracle 定义的替代品，也不是报告经验上限的先决条件。
3. 指标与学习器：仅使用预先允许的输入选择视角，与同权限基线比较。用闭环成功标签计算的经验 Oracle 只是参照，不是已经实现的算法。若要声称来源泛化，另行设计不参与开发的初态来源。

“随机”发生在噪声采样；按平均成功率取最大不是随机挑视角。有限重复的经验最大值存在选择偏差风险，但不能事先断定它虚高多少。重复完全相同的噪声检查的是可重复性，不替代独立噪声复评。

## 4. 旧 75.88% 的准确含义

旧 Broad M-B seed41 矩阵使用 8 个任务、每任务 8 个恢复快照，共 64 个起点，包含中间状态。每起点、每候选执行 32 次续跑，到任务目标成功或超时。相机起点设定后固定。

同一矩阵的规范、全局经验最佳固定、每任务经验最佳固定和每快照经验最佳分别为 64.70%、64.84%、69.34%、75.88%。

这些数值来自真实执行，未修改；但它们回答的是“从这些恢复快照继续完成剩余任务”，不能写成标准任务初态到终点的成功率。尤其 64.70% 是 Broad 模型使用规范相机的成绩，不是规范视角训练模型的成绩。

旧 16 个评价快照只是这类历史总体的一个划分，不是必须沿用的新主实验规模。新主实验是否使用 64 个初态，以及各任务初态数量、噪声预算，需后续统一冻结；不能因为旧数据叫“64 状态”就直接继承为“64 个任务初态”。

## 5. 论文论证的闭合路径

- 历史训练实验提供动机：训练覆盖改变被动视角鲁棒性，并存在性能权衡。
- 新主矩阵回答核心空间问题：从任务初态执行完整任务后，多视角训练是否仍留有候选视角收益，是否需要随初态选择。
- 指标与学习器回答利用问题：在允许的输入条件下，能否找到这些有利视角，并获得闭环收益。
- 独立复评回答稳定性问题：固定选定视角后，收益是否在另一批推理噪声中保持。
- 中间状态恢复分析仅用于机制或诊断；主动相机运动、腕部动作耦合、未见任务与真机作为后续扩展，不是当前已证实贡献。

当前已有实验不能直接填满第二至第四项。应如实呈现缺口，不用改变 Oracle 定义、挑选评价子集或拼接中间状态结果来填补。
