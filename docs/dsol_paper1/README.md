## 当前状态

- **研究主线**：冻结操作模型，以 Accel 决定已观察视角的选择，用 RL 减少搜索所需查询；从固定 97 点推进到连续 Δyaw/Δpitch＋STOP，再适配头部；动态候选保留为非学习对照。
- **已经完成**：固定 actor 的 A8/B8 共 15,488 条真实仿真任务；连续位姿/输入/返回复核 64 条去噪轨迹。另完成连续动作/STOP/返回工程准入36/64条，四状态通过；未训练、未执行新操作任务。旧实验不再运行。
- **训练完成、最终actor冻结**：连续 PPO 已完成512搜索回合、16次更新、1,919查询/3,838去噪轨迹；完整回合与原始查询哈希核验通过。仅采用预定最后一次更新，不按训练奖励或评测结果选权重。
- **连续评测完成**：192条任务、64组完整配对；不调整30/64、局部Accel30/64、连续PPO56/64；平均查询1、7.6875、7.75；两种搜索的换位伤害分别12/64、2/64。实际526条评分、7,252条执行去噪轨迹，无追加训练。四任务/八初态的开发证据，不代表完整benchmark或真机泛化。见[配对评测执行与统计](protocols/continuous_evaluation_zh.md)。
- **当前工作：4-worker准入后重训**：STOP探索项及混合初态修复已完成。已授权最多128条去噪轨迹的串行/4-worker一致性准入；通过后按原512回合/16更新、8,192条训练上限重训，首32回合/首次更新单独检查，失败就停。使用原始未训练初始化；不扩大并发，不自动重跑192条评价。唯一配置为 `configs/dsol_paper1/search/continuous_search_stop_mixed_v2.json`。执行进度以私有回执为准；见[训练驱动与并行边界](protocols/continuous_training_zh.md)。旧v1 actor、配置和结果保留。
- **暂存后续工作**：用户提供的私有机器人 URDF 已归档；相机标定及头部运动学接入尚未开展。
