### C. 形状分解：复杂曲面修正不总是更好

比较三个描述模型，模板记为T(q)，当前场记为A(q)：

1. `A(q)=a+bT(q), b>=0`：只调数值偏移和幅度，不翻转低高次序。
2. 在上式中加入3维坐标的线性残差：允许方向性差异。
3. 加入空间二次残差：允许更复杂的大尺度形状差异。

线性/二次残差可以改变低值位置，但**不是显式估计了物理相机位姿偏移**，也不能将改善归因于某个具体几何机制。模型分别有2、5、11个系数，约束模板系数非负。跨任务模板的绝对值本来已标准化，因此这里必须拟合幅度，不能比较未经校准的绝对RMSE。

全量拟合仅作描述；还做随机六折（每折80点校准、16点检查）和空间八象限留出。因此这不是少样本在线校准实验，更不是无需当前观察的部署方法。模板来源始终排除当前初态/任务；当前初态的留出视角标签不用于拟合。

空间块留出R²的逐初态中位数：

| 模型与模板 | 仅偏移+缩放 | 加线性空间修正 | 加二次空间修正 |
| --- | ---: | ---: | ---: |
| 规范训练，同任务 | 0.719 | 0.751 | 0.672 |
| 规范训练，其他任务 | 0.373 | 0.561 | 0.623 |
| 多视角训练，同任务 | 0.445 | 0.508 | 0.479 |
| 多视角训练，其他任务 | 0.336 | 0.313 | 0.339 |

R²评价数值重建误差，不是成功率、低值召回，也不是已识别的因果方差贡献。不同方法中位数之差不作显著性结论。完整图见[形状分解图](/share/longjunyu/alphabrain/experiments/dsol-standard-initial-aa0-v1-20260908/analysis/accel-template-v1/history/20260915T042459371469Z/decomposition.png)。

规范训练下，同任务形状可以较好复用；跨任务额外空间修正有描述性收益。多视角跨任务时，增加复杂度并未改善空间块预测；仅看全量拟合会高估价值。固定正仿射变换本身不改变排序；折外拼接涉及各折分别拟合，折外排序指标不能当成一个统一仿射函数的排序。

### D. 对后续路线的收敛

当前证据更支持先研究“模型相关默认低值位置/区域，遇到不适用的初态再修正”，而不是先重建整个空间后才允许找视角。一个较稳定低值位置可能已经足够作为恢复候选；还需与简单几何默认位置区分，不能直接当成新的自适应算法贡献。

| 当前初态与其余7任务构造的空间模板 | 0.681 / 70.8% | 0.553 / 68.8% |

跨模型、同初态的排序相关中位数为 **0.318**，低值重合为 **45.8%**。不能直接把一个模型的完整曲面移交给另一个模型。

跨任务模板只对其余任务的各初态场分别中心化并标准化，再平均；被评价任务不参与模板构造。它只检验已对齐相机参数下的相对形状共性，不预测绝对 Accel，不是真机零观察定位，也不是新场景闭环泛化实验。逐初态差异见下图，不能只看总体平均。

## 3. 插值能预测到什么程度

比较训练折均值、最近邻、全局二次曲面、分片线性、精确 RBF、平滑 RBF。所有方法固定后运行；未进行以闭环成绩为目标的参数选择。平滑 RBF 采用 thin-plate-spline、一次多项式尾项、归一化坐标下平滑系数 0.01，仅作为固定探索基线，不宣称最优。

两种视角留出：随机六折；按归一化空间八象限整块留出。每次留出一个位置时，该位置全部噪声一起留出。先在同一8噪声平均场内评价；另做前4拟合、后4评价及反向复核。所有初态的曲面分别拟合，不能将视角留出解释为初态或任务留出。

平滑 RBF 的逐初态中位数：

| 视角留出方式 | 规范训练 R² / 低值召回 | 多视角训练 R² / 低值召回 |
| --- | ---: | ---: |
| 分散点留出、同8噪声均值 | 0.539 / 70.8% | 0.518 / 66.7% |
| 空间块留出、同8噪声均值 | 0.329 / 66.7% | 0.186 / 62.5% |
| 分散点留出、评分噪声也分开 | -0.227 / 70.8% | -4.623 / 62.5% |
| 空间块留出、评分噪声也分开 | -0.384 / 62.5% | -4.576 / 54.2% |

低值召回：将折外预测拼回96个位置，选预测最低24个，与相应评价噪声下实测最低24个求交集比例。它是空间重建诊断，不是一个执行过的闭环选择器。

**不能省略负 R²：换评分噪声后，绝对值预测不可靠，但区域排序保留了一部分。** 进一步诊断发现共同上下偏移很明显。对每个噪声成员减去其96视角均值后，“8噪声均值的残余噪声方差 / 视角间方差”中位数约为0.059与0.133；不去掉共同偏移时为0.275与3.503。这只是描述性方差比，不是校准置信区间。结果支持区分绝对阈值与相对空间形状，不能以负 R² 等同于 Accel 恢复能力无效。

空间块留出会使许多测试点落在训练点凸包外，因此这项压力检验包含外推；完整数据见 `validation.json` 的 `interior` 指标。分片线性只在凸包内返回预测，覆盖率分别为60.4%与30.2%，不能将其有限覆盖成绩与覆盖全部点的方法直接当作同总体比较。

二次曲面并非普遍的单一凸碗：32个初态中，拟合 Hessian 正定的数量为15与19；正定且驻点位于参数包围盒内部的仅6与12。这里检查的是拟合模型，不能反过来证明真实函数不凸。当前不支持强行假设所有场景都有一个可直接求解的内部低谷。

这次使用的[平滑 RBF](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.RBFInterpolator.html)允许不精确穿过每个带噪点；[分片线性插值](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.LinearNDInterpolator.html)提供凸包内的对照。方法本身不能保证未观测处的物理真实性。

## 5. 当前可以据此推进什么

值得继续研究的是“模型相关的共同低值区域，加上任务/初态修正”，而不是所有模型共用一张曲面，也不是立即改为局部随机搜索。区域级预测比精准绝对值、单个最小点更有依据。未知视角的真实定位仍需可获得的几何对齐或观测，不能免费获知当前任务参考点和相机外参。

若后续需要确认插值误差，应先在预先固定的未测坐标直接渲染并计算 Accel；确认 Accel 连续场本身不必先执行完整任务。只有验证搜索终点的恢复效果时才需要完整闭环。该补测尚未启动，不因这份分析自动扩展到 SE(3)、新增场景或 RoboCasa。
