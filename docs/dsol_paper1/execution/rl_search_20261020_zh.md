用户已授权独立环境、2,048 步训练链路检查，以及通过后 3 seeds × 32,768 步第一轮训练。
本轮只在已有外部相机候选上做搜索；不加入虚拟头部约束，不改变操作模型与 Accel，
不启动旧队列、不执行新机器人动作。前置接口与数据说明见
[接口准入](../planning/rl_search_interface_20261020_zh.md)。

**最终状态：COMPLETE。** 100,352 个训练决策全部完成，新增 VLA 推理与仿真执行均为 0。
PPO 比不换位明显改善，但在主预算下尚未确认胜过局部 Accel；几何移动成本更高。

## 方法与比较范围

这是在旧缓存构成的环境上进行 **on-policy PPO**：当前策略选择下一候选，
环境解锁该候选已有观测和评分，再生成新的搜索轨迹。它不直接用旧机器人动作轨迹做 PPO，
也不是从离线行为数据估计重要性比率的 offline RL。
完整的 97 候选缓存让这一有限目录内的访问动作有可查询反馈；目录外位姿仍未知。
PPO 是常见基线，不意味着它必然胜过简单搜索。

操作模型是历史 LIBERO canonical 检查点，`framework.name=PaliGemmaPi05`，
`action_horizon=10`。这里不把它与 RoboCasa 的官方 OpenPI π0.5 运行链混写。
本轮根本不运行操作模型，而是读取其历史 8 噪声 Accel 和闭环标签。
原 canonical checkpoint SHA256：
`7e510b752143bb6fd4987988dfab5e94f7db1de5f7e97579f892a58eed22cc68`。

| 项目 | 实际定义 |
| --- | --- |
| 搜索 actor | 标准 MultiInputPolicy：字典观测展开，MLP 128×2，98 类输出 |
| critic | 同样可见输入，独立 MLP 128×2，输出预期剩余搜索回报 |
| 冻结部分 | PaliGemmaPi05 操作模型、缓存 ResNet18 特征、Accel 公式 |
| 动作限制 | STOP + 已访问候选边界上的新位置；采样与评价都提供合法动作掩码 |
| 防编号取巧 | 每回合随机重排候选槽位，观测、动作映射与掩码同步重排 |
| 提供的先验 | 已知 97 个候选的相对位姿，所有对照相同 |
| 未提供的内容 | 未访问图像与评分、成功率、可见性标签、规范图像、候选名和任务编号 |
| 标签使用 | 训练完成后独立评价；不作为 actor/critic 训练输入或奖励 |
| 数据划分 | 每任务初态 0/1 开发、2/3 评价，各 16 初态；8 个已知任务 |
| 起点 | 训练 1–64；评价 65–96。候选可在搜索期间访问，不声称候选从未见过 |

actor/critic 共 13,364,451 参数。两层 MLP 的结构简单，但高维特征展平产生较多参数；
这不是候选集合等变网络，也不支持不改输入层就改变候选数量。
本轮先兑现已登记基线，不在看到结果后改成 Transformer 或反复换结构。

## 运行与验收

独立环境：Python 3.12.3、CPU Torch 2.7.1+cpu、Gymnasium 1.2.0、
Stable-Baselines3 / sb3-contrib 2.7.0。完整传递依赖锁保存在本轮输出根。
系统缺少 ensurepip，未安装系统软件；用已有 uv 将依赖装入全新 venv，
不包含旧环境 site-packages，不改系统 Python/Torch。

这是单 CPU 进程，4 个 Torch 线程、16 个按顺序调用的 DummyVecEnv 逻辑环境，
不是 16 个并行训练 worker。因此不新建分布式队列，不申请 GPU。
后续若扩为多进程/多机，须接通用 execution 契约，不能复制当前循环当调度器。

工程检查：

- 独立 RL 环境相关测试 37 passed；合法动作概率屏蔽、隐藏输入、critic 输出和梯度通过。
- 2,048 步 smoke 的每个动作都检查合法性，actor 和 critic 均实际更新。
- 保存恢复后 policy、critic、优化器张量逐值相等；确定性访问序列、选位和 critic 输出相同。
- 保存恢复保证权重/优化器和确定性预测，不宣称保存了仿真中途的全部随机状态。
- 非法动作、非有限奖励/参数/梯度、预算不符、源文件变化均停止并保存失败记录。
- 负回报、负成功率收益、critic 解释率为负属于有效结果，不触发重试或参数调整。

执行参数固定在 `configs/dsol_paper1/analysis/search_ppo_first_round.json`：
每回合主预算 8；训练 seeds=0/1/2，smoke seed=17；
每更新 1,024 个决策（16×64），batch 64，4 epochs，lr=3e-4，
gamma=1，GAE=0.95，clip=0.2，entropy=0.01，value_loss_coef=0.5，grad_norm=0.5。
每 seed 最后一个 checkpoint 评价，不用评价集选最优轮次。

第一轮预算总计 100,352 决策步。三个评价预算 4/8/16，
PPO 共 4,608 个缓存评价 episode。每格随机对照也用 3 个 seed；
不换位、固定扫描、局部 Accel 为确定性对照。
每个初态内先平均起点与 seed，再按任务/初态层次计算区间。
机器人执行重复用于同初态、同起点的噪声配对，不把 512 个起点实例当成 512 个独立初态。

过程保留每个已完成搜索 episode 的访问路径、查询数、回报、选位；
每次 PPO 更新记录策略损失、价值误差、解释率、KL、裁剪比例及梯度范数。
完整结果保留所有方法、任务、起点、seed 和预算；不只展示赢家。

## 结果边界与后续

主预算 8 的配对缓存结果：

| 方法 | 成功率 | 相对不换位 | 实际查询 | 几何移动单位 | 搜索回报 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 不换位 | 22.41% | — | 1.00 | 0.00 | 0.0000 |
| 固定扫描 | 34.65% | +12.24 pp | 8.00 | 48.05 | 0.2968 |
| 随机搜索 | 34.31% | +11.90 pp | 8.00 | 52.02 | 0.2777 |
| 局部 Accel | 36.90% | +14.49 pp | 8.00 | 30.56 | 0.3213 |
| PPO | 37.82% | +15.42 pp | 7.01 | 45.70 | 0.3186 |

PPO−局部 Accel 为 +0.93 pp，任务/初态层次配对 95% 区间 [-3.28,+4.75] pp；
不能确认稳定胜出。PPO−随机搜索为 +3.52 pp，区间 [+1.25,+5.83] pp；
这是已看过数据上的开发证据，不是独立确认。
三个 PPO seed 成功率为 37.54%、39.40%、36.53%，全部报告，不选最佳 seed。

PPO 少约 12.38% 查询，但几何移动单位多约 49.53%。对应累计路径为
3.79 米/116.68 度，局部 Accel 为 2.54 米/77.46 度，均为候选图几何代理，
不是执行过的物理轨迹。因此不能把少查询直接说成省时间或整体更高效。
PPO 搜索总回报也未高于局部 Accel。

| 查询上限 | PPO 成功率 | 局部 Accel 成功率 | PPO / 局部实际查询 |
| --- | ---: | ---: | ---: |
| 4 | 29.91% | 27.69% | 3.78 / 4.00 |
| 8（主） | 37.82% | 36.90% | 7.01 / 8.00 |
| 16（预算变化） | 46.34% | 50.03% | 10.49 / 16.00 |

预算 4 时固定扫描 30.78% 高于 PPO；预算 16 时 PPO 低于局部搜索，但查询数不同，
不能把差距全部归因于选择错误。未训练 16 次预算，不能声称已验证任意预算泛化。
逐任务 PPO 相对局部 Accel 有正有负：奶酪放碗约 +7.26 pp，书放收纳架 +6.46 pp；
奶酪入篮约 −10.42 pp，酒瓶入架 −2.31 pp。每任务仅两评价初态，不下普遍机制结论。

训练曲线显示回报提高、critic 误差下降；末四更新的解释率约 0.19–0.20，
仍不足以认为价值估计准确。它验证训练链路和有限学习信号，不证明已经学会可泛化搜索。
actor/critic 的输入、动作屏蔽、预算及保存恢复均通过；负结果原样保留。

历史矩阵完整，足够第一轮缓存搜索；独立物理场景仍只有 16 个开发初态和 16 个评价初态。
历史评价结果此前已被分析，不能称独立盲测、新任务泛化或头部迁移验证。
奖励降低 Accel 不等于提高任务成功率，必须把二者与实际查询成本一起看。

在线适配时，把缓存查询换成相机到达后采图、冻结操作模型预测并提取 Accel。
随后才加受约束头部动作。迁移时需要重新核验相机视域、操作模型输入分布、
相机运动影响和实际延迟，不能直接套用旧端点标签。

下一轮优先级：先显式提供由已知候选图计算的到达/返回成本，或采用共享候选编码器，
检验能否减少不必要的远距离切换；二者需独立对照，不在本轮改奖励、加训练预算。
这些成本不依赖未访问图像或成功率，不属于结果泄漏。现有结果没有证明必须加大网络，
也没有证明 PPO 本身无效。先解决搜索结构和停止决策，再谈跨模型/头部迁移。
