# 三模型主线：π0.5、GR00T N1.5、DiT4DiT

2026-10-28，北京时间。用户明确保留π0.5和GR00T N1.5，并要求另找第三模型替代SmolVLA。本次推荐第三模型为 **DiT4DiT原作者实现**，FastWAM为资产/运行成本无法满足时的备选，SmolVLA退出首版三模型计划。本次是选型与静态接口核查，没有新训练、推理、仿真或GPU任务。

## 选择依据

优先级由两基准检查点可获得性、操作能力证据、模型家族差异、原生flow轨迹可读取性及接入成本决定，不根据本方法在候选模型上的提升选择。DiT4DiT用Cosmos视频骨干和flow-matching动作头，区别于π0.5、GR00T的VLM主干路线。它复用部分GR00T/StarVLA实现原语，不声称全部代码或动作头设计独立；第三模型的价值是不同视觉建模路线，而非把GR00T换个版本凑数。

原作者[仓库](https://github.com/Mondo-Robotics/DiT4DiT)同时提供LIBERO和RoboCasa GR1部署文档。当前README列出LIBERO平均98.6%，GR1同一检查点五次评测平均分别56.7%、56.6%、56.3%、57.4%、57.3%。这是作者报告的基础操作结果，不是我们的复现，更不保证扰动后的可恢复性。

论文v1报告GR1为50.8%，与当前README不一致，保留该版本差异，不把后续README数字冒称原论文数字；执行时固定实际检查点及其源码/协议，单独报告我们的完整基础能力。来源：[论文v1](https://arxiv.org/html/2603.10448v1)。

模型目录已通过网页查看：

- [作者LIBERO权重目录](https://huggingface.co/mondo-robotics/dit4dit-model/tree/main/dit4dit_libero)：约21.3GB，含final_model、config.yaml、dataset_statistics.json。
- [作者GR1权重目录](https://huggingface.co/mondo-robotics/dit4dit-model/tree/main/dit4dit_robocasa_gr1)：约21.3GB，同样有配置与统计。

两目录约42.6GB是公开页面所示文件体量，不是GPU显存需求，也不包含所有外部依赖。不下载训练数据、不另训操作模型，仅准备冻结已有操作权重和训练我们的G搜索策略。公开目录存在不代表下载已完成或本机加载已通过。

## 原生Accel接口可行性：静态核查已完成

固定源码commit：`66a6f3a12e2c8740157c1e478795952c040d31dd`。

`DiT4DiT/model/modules/action_model/ActionDiT.py::predict_action`从高斯噪声出发，用原生Euler执行 `actions = actions - dt * pred_velocity`，t从1走向0。读取每步原始动作和速度可构建评分轨迹；这只是结构兼容，不是评分已证实有效。不得把实际机器人动作时间上的加速度与采样时间上的Accel混淆。

公开检查点配置：

| 条件 | 内部动作窗口×维度 | 原生动作采样步数 | 状态维度 |
| --- | --- | ---: | ---: |
| LIBERO | 8×8 | 4 | 16 |
| GR1 | 16×32 | 4 | 64 |

内部维度不等于全部有效控制维度，须结合解码与mask冻结Accel计算范围；不能直接套用π0.5内部32维。两配置均有`future_num_inference_steps=1`与2048宽特征。视频骨干随机性须单独记录并配对，不能只固定动作初始噪声就宣称全输入相同。PPO使用新特征接口，不能直接加载旧π0.5搜索actor；算法G、reward定义和在线尺度更新原则保持统一。

不为了“对齐十步”擅改原生四步采样；先实现只读trace，测试动作逐值一致、RNG/批处理不变、动作和视频调用分别计费。四步动作头不意味着端到端一定快于π0.5，骨干开销与显存必须实测。调度仍用现有统一queue/ledger，不运行上游自带派发器。

## 当前真实缺口与备选

原作者加载路径依赖 [Cosmos-Predict2.5-2B](https://huggingface.co/nvidia/Cosmos-Predict2.5-2B)，官方页面要求账户同意后访问；这与此前GR00T N1.7的Cosmos-Reason2是不同模型，访问许可不能混用。当前仅在个人项目 `pretrained_models` 下做了限定深度目录名检查，未发现Cosmos/DiT4DiT缓存，不代表全共享盘不存在。没有读取认证、接受协议或绕过访问。

本机匿名获取作者模型API和Cosmos小配置本次TLS握手超时，未得到HTTP 401/403，不把超时误记为访问拒绝；网页读取成功与本机直接下载链分开记录。公开API失败与成功的其他小文件证据均落盘。真实权重哈希/骨干合法缓存/环境与本地吞吐尚待确认，当前不标记READY_TO_RUN。

若依赖可用，选DiT4DiT原作者两端实现，不混入FluxVLA重实现的57.25%成绩。FastWAM作为单一备选：官方有LIBERO操作权重，FluxVLA有GR1后训练权重条目和49.92%外部报告；其Wan路线也有flow动作轨迹。两端来源不同、额外依赖与吞吐仍需核验，不把它假定为零成本替换，不同时启动第四模型大实验。

## 后续实施顺序

1. 原生π0.5完整结果已经成立，继续论文分析，不重跑。
2. GR00T N1.5、DiT4DiT分别冻结各基准的权重/源码/归一化/动作与相机协议；优先接通原始操作和只读评分，再复用G训练及配对恢复评测。
3. 各模型内部统一比较规范参考、扰动保持、机械回零、局部Accel、G；不同模型训练PPO时沿用既定训练/开发/未见任务隔离，不复用测试成功率调尺度。先不把A/B/L及所有模型版本全部铺满。
4. 两个新模型的实际调用预算、显存容量和耗时由对应原生运行实测后冻结，不复用旧许可，不承诺三模型同时48worker。首要目标是跨冻结flow操作策略的恢复验证，DiT4DiT应准确标记为Video/Vision-Action Model，论文不称三者都是同类VLA。
