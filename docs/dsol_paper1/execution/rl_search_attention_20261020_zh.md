## 有界诊断准备，尚待失败后的显式恢复

代码提供 `--batch-check`，不触发训练/导出/任务：

1. 同一开发初态、评分成员0，重放历史前16候选批次：16条去噪轨迹。
2. 同一规范视角重复16次，保持 batch 形状：16条去噪轨迹。

两批都逐值核对历史分数；第一批失败立即停止，不执行第二批。
若批准，累计最多36/114；诊断输出另立目录，保留首次失败。
若两者均通过，才有证据将当前差异归到批量执行路径；它仍不意味着 batch1 已准入。
继续路线须明确二选一：部署保留已验证的批量形状，或重新生成与在线 batch1 匹配的
评分数据。后者32×97×2需要6,208条去噪轨迹，超出现有“只导出视觉”的预算，
不能未获批准启动。前者有重复计算成本，不能伪装成一次真正廉价的单噪声调用。

本轮问题不应通过降低阈值、忽略失败或挑另一初态来绕过。
