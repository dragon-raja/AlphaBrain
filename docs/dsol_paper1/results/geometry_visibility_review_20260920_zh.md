# 相机几何与可见性分层：审查稿

2026-09-20。复用LIBERO冻结数据及RoboCasa正式release的相机安装缓存；新增训练、VLA推理、渲染、闭环均为0。
不修改运行中的RoboCasa评测，不重建或替换当前PDF。待用户审查后决定哪些图进入报告。

## 结论摘要

1. 候选确有平移：方位角与仰角都是绕参考中心移动相机，距离倍率是径向平移，不是变焦。32初态的3072个非规范候选全部有位置变化；相对规范相机位移最小0.0241m，中位0.8456m，最大1.8205m；各初态内97候选的相机内参哈希一致。
2. 排除“至少一登记任务实体外部可见像素为0”的扰动起点后，Accel规则仍有平均恢复收益。评价范围仍覆盖8任务、16初态，保留380/512个留出目录起点。
3. 不能将此解释为完全控制了信息量。>0像素只排除完全没有该实体分割像素的情况，不保证完整可见、清晰或足以完成任务；腕部视图保持原协议。
4. 多视角模型上，最高可见性规则不优于保留可见起点；预算16的Accel搜索均值也未超过同预算随机搜索。恢复价值与搜索策略优越性须分别报告。
5. 规范参考几何基线很强。已知规范位置后，选择最接近规范位置的非规范候选可得到82.81%/86.13%；这种参考标定权限不同于无规范标记的搜索，不能混作同权限方法。但不能忽略它对“回到熟悉几何是否足够”的提示。

## 图2：为什么仰角也有位移

![三个参数的几何含义](/workspace/research-reviews/view-geometry-visibility-20260920/03_orbit_axes.png)

相机位置满足 p = pivot + r·s·[cos(e)cos(a), cos(e)sin(a), sin(e)]。改变方位角a或仰角e都改变p，同时朝向参考中心。只有“相机中心p固定，仅旋转相机坐标系”的原地俯仰才没有平移；本实验不是这种操作。

此图是从保存参考外参解析计算的单轴轨迹，不代表新增视角已评测。已用同一公式重建所有3072个已测候选位置和朝向，与实测外参逐项核验，详见[几何核验](/workspace/research-reviews/view-geometry-visibility-20260920/geometry-validation.json)。

## 图3：仅筛起点，方法不改

![起点可见性分层后的原方法成绩](/workspace/research-reviews/view-geometry-visibility-20260920/04_visibility_strata.png)

口径：8个已知任务，每任务初态2、3评价，初态0、1属于旧开发划分。每个评价初态原有32个留出目录扰动起点；512个起点中380个满足所有任务实体外部分割像素>0，132个不满足。两组均保留全部16初态。没有把像素为0的原始数据删除；全体、非零、含零三组并列。

每个终点成功率来自32套已完成的整任务执行噪声。先平均每初态保留的起点，再等权汇总任务/初态；不是把380个起点当380个独立场景。由于各初态保留数量不同，两组总体均值不能直接按380:132加权还原原总体。

| 仅非零像素起点 | 规范训练成功率 | 相对原位提升及95%区间 | 多视角训练成功率 | 相对原位提升及95%区间 |
| --- | ---: | ---: | ---: | ---: |
| 保持原位 | 28.89% | — | 79.12% | — |
| 全候选最低平均Accel | 65.43% | +36.54 pp [16.73,56.47] | 86.52% | +7.41 pp [1.13,14.88] |
| 全候选最高可见性 | 41.80% | +12.90 pp [-3.32,30.22] | 77.93% | −1.19 pp [-9.70,6.07] |
| Accel最低10个再选可见性 | 69.73% | +40.83 pp [18.09,63.03] | 86.13% | +7.02 pp [0.76,12.30] |
| Accel搜索，预算16 | 52.63% | +23.74 pp [13.12,34.07] | 83.74% | +4.62 pp [0.94,8.70] |
| 随机搜索，预算16 | 48.05% | +19.15 pp [12.19,25.11] | 83.83% | +4.72 pp [1.33,8.36] |

区间为任务/初态分层配对bootstrap，条件于已测噪声库；不是新盲测，也没有多重比较或Oracle最大值偏差修正。随机搜索是随机扩展邻接边界后选访问点中最低Accel，不是随机直接执行一个终点。

为什么全候选规则在三组中的成功率不变？它们每个初态选一个终点，不依赖起始相机；本次分层后16初态均保留、仍等权，因此选后均值不变。但原位基线和恢复增益变了。有限查询搜索依赖起点，所以选后成绩也变。

## 图4：限制终点，是另一个诊断

![可见候选约束](/workspace/research-reviews/view-geometry-visibility-20260920/05_visible_destinations.png)

此处起点仍用380个非零像素起点；终点只允许全部任务实体外部像素>0的候选，包括规范候选。限制条件使用仿真分割真值，因此是特权诊断，不是宣称新算法无需获取就知道所有候选是否可见。

| 可见候选中选点 | 规范训练 | 多视角训练 |
| --- | ---: | ---: |
| 均匀选一个可见候选的期望 | 28.37% | 79.40% |
| 最高可见性 | 41.80% | 77.93% |
| 最低平均Accel | 65.43% | 86.52% |
| Accel最低10个再选可见性 | 69.73% | 86.13% |

三条确定性规则的终点成功率都没有改变；这批评价初态上原先选出的终点已经满足非零条件。它们并非仅靠把零像素候选排掉就得到同等成绩。但“可见候选均匀选”使用全部97目录中的可见子集，而保持原位用32留出目录中的可见子集，不应将二者视作完全同分布。

补充秩诊断：在每初态的非零像素非规范候选中，低Accel与高成功率的Spearman中位数为0.507/0.202（规范/多视角）。最低四分之一与最高四分之一的成功率分别为46.41%对15.82%、82.71%对76.73%。进一步按可见像素占比排序分四组后，组内相关的描述性中位数为0.512/0.225；这些分组不等于任务信息相同，也不是因果识别。

## 规范几何参考与不能越界的解释

同样在非零像素起点上，已知规范位置后选最接近规范位置的非规范候选：82.81%/86.13%；选朝向最接近规范朝向的非规范候选：58.59%/87.11%；直接返回规范视角：90.63%/88.67%。二者的距离分别使用真实平移欧氏距离、SO(3)角距离，不用闭环成败选择终点。

它们拥有规范标定参考，和不输入规范标记的搜索不是相同权限。结果提示需要保留几何基线，不能将Accel收益直接归因为“新任务证据获取”或断言优于“恢复熟悉视角”。本次也没有证明Accel就是熟悉度。

可支持的表述：**在过滤零像素扰动起点后，Accel规则仍显示平均恢复收益；仅最大化任务实体像素占比不足以解释或实现相同收益。** 不可扩展为“信息量完全相同下的纯视角因果效应”或“真实主动运动已验证”。

## RoboCasa补充：相机架几何、覆盖范围与统一解释

2026-09-21后续核验：[主动相机可行性报告](../history/planning/active_camera_feasibility_20260921_zh.md)。10个预选seen初态中已发现部分候选中心进入柜门/柜板碰撞几何；因此下文“未证明物理可达”不应读作“只是形式上的声明”。原矩阵与本页几何统计未改，需另外做基于物理标记的分析。

### 保存的是真实安装位姿，而不是全程世界轨迹

![RoboCasa双目架位置与光轴](/workspace/research-reviews/view-geometry-visibility-20260920/robocasa/01_linked_rig_installations.png)

蓝色为左外部相机，橙色为右外部相机；细连线连接同一个候选中的左右相机。绿色虚线表示双目中点的平均观察方向，黑叉是规范双目中点沿平均方向前进1米得到的几何参考中心。不是从任务物体真值计算的中心，也不保证左右各自的光轴精确通过该中心。视锥采用已保存安装外参和原模型60°垂直视场角绘制，显示长度截断，不代表有效深度或无碰撞空间。

坐标是两只外部相机共同父节点`mobilebase0_support`的局部坐标，不能标为世界坐标或运动轨迹。示例是冻结计划中第一个seen初态（CloseBlenderLid seed 0），展示的视锥按固定索引抽取，没有使用成败选案例。可视化之前，所有400初态的相机顺序与编译XML位置、候选顺序和release哈希进行了核对；采用正式release中的`candidate_root`，而非可能已被替代的旧构造目录。

核验400初态 × 97候选，合计77,600条左右相机安装记录；其中76,800条非规范记录的统计如下。

| 项目 | 实测 |
| --- | --- |
| 相对规范的单相机平移 | 最小0.1113m，中位0.3597m，最大0.7189m |
| 相对规范的单相机光轴夹角 | 最小3.733°，中位17.870°，最大31.837° |
| 双目间距 | 全部0.7000m；单初态跨候选最大误差1.89×10⁻¹⁵m |
| 左右相机相对旋转 | 跨候选最大矩阵分量误差1.36×10⁻¹⁵ |
| 腕部及其他相机安装 | 400初态全部逐值保持不变 |
| 双目中心射线与参考点关系 | 最大分量误差1.89×10⁻¹⁵m |

这是刚性双目架的三参数变化，不是两只相机各自自由选择，也不是改变焦距。安装偏置在初态选择一次、整条任务保持不变；相机世界位姿满足`T_world_camera(t) = T_world_support(t) × T_support_camera(candidate)`，因此随原生支撑体运动。腕部安装不变也不意味着腕部图像不变。本次没有读取全程位姿轨迹，不能据此声称每个任务底盘都确实移动了多少。

### 训练目录与留出目录

![RoboCasa目录与实际位移](/workspace/research-reviews/view-geometry-visibility-20260920/robocasa/02_candidate_coverage.png)

64个训练目录点为4×4×4规则网格：方位`[-30,-10,10,30]°`，仰角`[-15,-5,5,15]°`，距离倍率`[0.8,0.9333,1.0667,1.2]`；32个留出点为同范围内的scrambled Sobol，seed41；另有1个规范安装。训练目录64不等于每条训练轨迹渲染了64遍，正式多视角训练采用每轨迹两种安装曝光。

右图计数是重复场景中的相机几何记录数，不是独立几何类型数或成功率。它显示平移与光轴变化被生成规则耦合；不应将这种关系当作模型学到的规律。

进一步对全部导出的安装记录按候选身份对齐：400初态之间，同一候选的支撑体坐标最大位置差2.00×10⁻¹⁵m、光轴分量差9.99×10⁻¹⁶。即本体局部安装模板实际上相同，变化的是任务场景、物体和机器人初态，不是400套独立几何空间。这种重复有利于控制比较，但不能把77,600条记录作为独立视角类型的diversity。相同安装在不同场景产生不同观测和闭环表现；也需保留不读图像的模板基线，判断方法是否真正利用新场景证据。

### 当前评测应继续，结论范围需要准确

在冻结候选族内，配对比较相同模型、初态、噪声和任务预算，能够研究：（1）多视角训练带来的覆盖收益及规范安装代价；（2）从留出扰动起点保持原位，与按指标选择终点的恢复差异；（3）不同训练条件下指标与闭环表现的结构关系。RoboCasa这些效应仍应等待矩阵完成后计算，几何核验不替代成功率结果。

当前实验估计的是既定候选分布上的平均效应，不是对所有相机位姿成立的定理。若它呈现恢复收益，可以称为“该安装扰动分布下的初始视角选择/恢复”；不能直接称“真实主动相机获取已完成”。若没有收益，也不能推出其他候选族或动态主动感知无价值。

### 后续优化顺序：不推倒当前矩阵，不无限扩展SE(3)
