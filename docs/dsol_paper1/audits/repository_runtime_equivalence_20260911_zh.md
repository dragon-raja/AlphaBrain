# 仓库迁移后的闭环一致性验收

## 目的与边界

本项验收比较冻结正式实验的旧执行链与模块化后的新执行链，检查目录、导入和模块拆分是否改变实际运行。它不是新增科学实验，不用于更新成功率、Oracle 或选择器结论。

正式实验保持为 8 个任务 × 4 个官方初态 × 97 个固定外部视角 × 32 套显式 Flow 噪声 × 2 个模型，共 198,656 条结果。原始结果、冻结源码、权重及当前 PDF 均不覆盖。

## 对照设计

- 使用原 `release.json` 已有的 48 个 `gate_indices`，不根据本次成败重新选样。
- 这 48 个键覆盖 8 个任务、规范/训练候选/留出候选三类视角、2 套噪声；每任务取一个原验收初态，跨任务覆盖四个初态编号。不是对全部 32 个任务初态的完整验收。
- 两个模型各跑旧、新入口，合计 192 次整任务闭环、96 对新旧对照。
- 每次从官方初态完成整个任务，外部视角全程固定；不引入中间态恢复或任务途中换相机。
- 保持原权重、输入、AA0 渲染、10 步 settle、每 5 个动作重规划、10 步去噪及显式噪声带不变。
- 新执行链使用 Git 提交快照，旧链使用原冻结副本。核对实际模型模块来源，防止新入口意外调用旧模型代码。

## 通过条件

每对结果必须同时满足，不以浮点容差或相近成功率替代：

1. 成败、完成步数、调用次数和物理步数完全一致。
2. 完整生产轨迹摘要完全一致；摘要覆盖运行链记录的输入、动作及物理轨迹。
3. 每次策略请求的数组身份、元数据、动作完全一致。
4. 模型实际接收的初始 Flow 噪声等于指定噪声，实际 10 次去噪时间输入逐项一致。
5. 旧、新入口均与正式实验保存的原验收轨迹一致。

观察器仅记录原推理函数的输入、输出及去噪输入，不增加推理次数。先运行一对完整轨迹，通过后才扩展剩余对照；任何差异停止验收并保留证据。

## 首轮发现及修复

首轮验收发现新链在 Python 3.8 仿真进程中导入失败。将噪声实现迁入研究包后，包的 `__init__.py` 提前导入协议定义，间接触发 `dataclass(slots=True)`；该参数不被 Python 3.8 支持。

修复为按需导出协议 API，使仿真进程只加载所需的噪声和可见性模块。没有修改协议定义、模型、噪声采样或计算公式。实际 Python 3.8 叶模块和控制器导入已验证通过，原公共 API 保持不变。完整 CPU 测试为 586 项通过、182 项子测试通过。

这是真实的迁移兼容回归，不能用之前 CI 通过来否认；它发生在新入口开始 rollout 之前，不构成冻结正式结果已被改变的证据。首轮旧入口完成的轨迹与原归档完全一致，失败记录保留于共享盘的 `repository-runtime-20260911-v1`。

第二轮首对轨迹通过，但进一步核对实际导入来源发现：旧控制器的历史目录绑定仍优先加载前序冻结仓库的相机与观测工具。已主动停止第二轮，不将混合来源的运行宣布为完整迁移验收。修复为进程内共享工具从执行代码自身所在仓库导入；冻结数据与历史子进程重放路径不变。第三轮增加来源硬检查，要求新链已记录的全部项目模块都来自新快照。第二轮状态中的 `User interrupted` 是诊断工具对 SIGTERM 的通用标记，此处为代理主动停止，并非用户手动终止。

## 最终验收结果

**通过。** 第三轮完成全部 192 次整任务闭环，96 对新旧比较均逐项精确一致，并且全部匹配原正式实验的验收轨迹。执行阶段耗时 894.89 秒（约 14.9 分钟，不含前置权重哈希检查及前两轮排查）。

| 检查 | 结果 |
| --- | --- |
| 完整闭环轨迹、成败、步数 | 96/96 对精确一致 |
| 首次输入数组文件 | 96/96 对字节一致 |
| 逐次请求输入、元数据、动作、实际初噪 | 4,451/4,451 对一致 |
| 模型实际去噪时间输入 | 44,510/44,510 对一致 |
| 新链全部记录的项目模块来源 | 96 个当前版本闭环均来自新源码快照 |

| 最终本地测试 | 完整 CPU 588 项 + 182 项子测试；可移植测试 66 项通过 |
| 进程清理 | 仅停止本次自建服务；8 个原有 keepalive 进程保持运行 |

## 维护入口

显式运行工具为 `tools/paper1/verify_runtime.py`，观察器为 `tools/paper1/runtime_probe.py`。默认只准备计划；只有 `--execute` 才启动 GPU 对照。必须指定新的输出目录，既有验证不覆盖。工具不结束其他进程、不升级冻结运行环境，也不自动启动全量重评测。
