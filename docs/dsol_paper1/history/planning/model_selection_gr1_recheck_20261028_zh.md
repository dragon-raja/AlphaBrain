# 第二模型重新选型：优先覆盖LIBERO和GR1

2026-10-28，北京时间。本轮为用户追问后的公开来源核查和优先级建议，零模型加载、零GPU任务、零新增训练。接续同日 `mainline_after_coordinate_validation_20261028_zh.md`：其中SmolVLA优先的方案不再作为下一步默认安排，原生G的完整通过结论不变。

## 决定与理由

建议π0.5维持主模型；第二模型改为优先核验GR00T N1.5的LIBERO与GR1两端资产及接口，SmolVLA降为可选轻量补充。选择依据是跨基准可用检查点、已有操作能力证据、模型家族差异和工程复用，不按我们方法提升多少择优选模型。不为赶论文另训SmolVLA操作策略，也不重新训练已完成的原生π0.5实验。

“对照”有两层：同一操作模型内部，保持/回零/原参考/局部/G比较证明我们方法的作用；跨π0.5与GR00T比较检验模型适用性。后者尽量覆盖两环境，但不同本体须使用各自匹配的操作权重，不能要求同一权重直接通用。若某一环境尚未接通，可先形成已有模型结果，不把整个项目锁住。

## 新核实的证据

[FluxVLA发布方README](https://github.com/FluxVLA/FluxVLA#robocasa-gr1)在RoboCasa GR1 24任务、每任务50次报告：

| 发布方实现 | 数据/设置 | 报告成功率 |
| --- | --- | ---: |
| SmolVLA | 全量数据、冻结VLM | 8.75% |
| GR00T N1.5 | 每任务30示范 | 44.3% |
| GR00T N1.7标签 | 全量数据，见骨干差异说明 | 46.42% |
| π0.5 | 全量数据 | 51.42% |

这些是发布方结果，训练设置不相同，不是受控架构排名，更不是本项目复现成功率。SmolVLA一份配置表现低不能推出该模型普遍不行；但它不是当前紧迫排期下优先投入GR1的充分理由。低操作基线会让视角损失与恢复的解释更困难。

SmolVLA并非完全没有GR1：NVIDIA发布的 `smolvla-arena-gr1-microwave` 有[LeRobot官方评测入口](https://huggingface.co/docs/lerobot/en/envhub_isaaclab_arena)。它属于IsaacLab Arena微波炉任务，不是RoboCasa GR1 24任务；不能把有单任务权重说成多任务能力已充分。

当前公开Hub元数据revision `1b24eb97cbec6da523e2ea32c3600c467b18e090`中，GR00T N1.5四个LIBERO子套件和GR1各有权重文件；第三方N1.7标签也有对应文件。只核对文件存在和小配置，没有下载或校验新大权重，没有加载执行。SmolVLA GR1 README所链目录本次返回404，Hub清单也未见该精确目录，因此其报告结果与检查点当前可获取性分开记录。

**第三方N1.7不是已确认的官方等价实现。** 下载其小配置后，`model.vlm_backbone.type=GrootN17Qwen3Backbone`，骨干配置为`qwen3_vl`；不能以此宣称已解决官方Cosmos依赖，或与官方N1.7的LIBERO权重混作同一模型。若今后使用，应准确命名第三方实现并核对两端骨干、动作头和预处理。

NVIDIA官方GR1入口仍要求finetuned checkpoint路径；[官方仓库问题749](https://github.com/NVIDIA/Isaac-GR00T/issues/749)追问该权重定位，本次读取仍open、0回复。该issue不能证明全网不存在权重，但官方表格成绩不是可直接加载的资产凭证。

另一个独立原始来源[ChunkTrust论文](https://arxiv.org/html/2609.39754v1)报告GR1 24任务基础π0.5/GR00T N1.5/N1.6为40.08%/43.25%/47.61%。其π0.5是我们此前找到的另一路候选，不与FluxVLA的51.42%混合或直接归因于架构；训练配方、检查点、执行协议不同。优先保证单个冻结策略在本项目的规范/扰动/恢复对照一致，而非追逐最高外部数字。

## 下一步具体范围

1. π0.5：已有LIBERO完整结果直接成稿。GR1先核对已选第三方操作模型原始协议与能力；不为了这个调查切换正在使用的原生权重，不叠加ChunkTrust的执行时域算法。
2. GR00T N1.5：复用已有官方基础权重和固定源码；同时核对公开LIBERO后训练权重、GR1版本及processor。选择一致实现路线，记录是否基准后训练；“同家族”不冒称“相同权重/相同训练数据”。已有共享权重无需重复下载。
3. 只训练我们的G搜索策略，冻结操作模型；沿用任务/初态隔离、在线尺度、配对噪声、成功率/净恢复/损害/查询指标。新模型Accel的有效维度、积分时间和特征适配需先固定，不能盲套π0.5内部32维。
4. SmolVLA现有权重/CPU代码保留，不投入其完整PPO/GR1训练。N1.6、官方N1.7及第三方Qwen3版本保留候选，不并行展开三套大实验。
5. 不把外部约40%–50%基础成功率称为“足够高且必然能恢复”。采用事先列出的完整任务诊断，报告规范与扰动损失；不按成功或恢复效果筛任务。实际预算与吞吐在具体接口和运行清单确定后给出，本次选型不是新实验许可。
