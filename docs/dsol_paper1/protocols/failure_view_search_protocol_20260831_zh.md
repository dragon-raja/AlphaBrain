# 困难状态全候选视角搜索

本轮补齐“规范视角失败时，候选池中是否存在可重复有效的视角”这一证据链。不重新训练，不改原可见性公式，不用可见性或 Accel 预筛候选，不重排原 PDF。

## 冻结设计

- 发现状态：已查看的 84 个构造状态中，规范视角在原 5 次筛查中至少失败 3 次的全部 20 状态；17 条源轨迹、6 个任务。
- 这些来源已用于事后分析，本轮明确标记为发现集，不是新的独立来源测试。筛查失败不保证换新噪声仍失败，所有状态均保留并重跑规范条件。
- 每状态完整保留规范、64 个训练目录位姿、32 个同范围留出位姿。共 97 个候选，不依据像素或 Accel 删除候选。
- 发现噪声：20260861、20260862、20260863。共 20 × 97 × 3 = 5,820 条闭环。
- 复验：每状态冻结行为排序前 4 个非规范候选、规范视角、1 个发现阶段低成功候选、2 个几何多样性对照。8 个候选使用新噪声 20260871 至 20260875，共 800 条闭环。
- 主规则：仅使用发现阶段的成功率、完成步数、固定 ID 顺序选出 Top-1；复验后不换赢家。最优集合与其他候选的复验标签仅作探索性分析。
- 模型：同一 Broad64 practical seed41 checkpoint；K=5；wait=0；从原中间状态执行到正式任务成功或套件超时；腕部相机正常更新，外部相机选定后固定。
- 运行保留现有全部 GPU keepalive。8 个策略服务、32 个 simulator worker；逐 episode 落盘，已完成记录不重复执行。
- W&B 仅允许配置与标量；无登录/网络失败自动离线，媒体、权重、数据、认证文件不上传。原始结果与全部复验视频保留本地。

## 分析与限制

首先报告完整 `state × candidate × noise` 成功矩阵、每任务有效候选占比、有效候选是否形成连续区域，再分析可见性、各实体、相机方位与支持域。特征统计必须在同状态内对照，不能把容易任务和困难任务混在一起求相关后解释为视角价值。

独立复验主结果为预先冻结 Top-1 相对同步规范视角的收益，按源演示成组 bootstrap。逐候选探索标签暂定义为复验成功率至少 80%、相对规范提升至少 40pp；五次重复并不足以给每个候选作高置信、多重比较校正后的显著性声明。

本轮不证明训练泛化、通用信息量、真实机械主动视觉或腕部独立控制。候选池上限仍受这 97 个位姿限制。后续学习须使用独立来源/任务验证，同时补成功状态的无伤害对照；不得在当前已查看的 42 条来源上调规则后再称为独立测试。
