# 扰动视角恢复：部署权限与离线验证协议

本轮经用户确认，将主比较从“是否超过规范视角”调整为“受扰动后，选择是否优于保持原位”。不改变原 VLA 权重、32 官方初态、97 候选、32 闭环噪声或已有成功判据。配置、拟合与离线图搜索属于新探索分析；旧协议、原始结果及旧选择器产物保留。

## 已实施的范围

- 每任务初态 0、1 开发，2、3 评价；仍是 8 个已知任务，不是 unseen-task 实验。
- 所有 96 个非规范相机均作为起点，分别汇总全部 96、训练目录 64、留出目录 32。PDF 主恢复对照采用留出目录 32 个起点均匀分布。
- “留出视角”是 VLA 训练目录划分；开发初态的这些候选标签仍用于选择器训练，因此不是选择器视角留出。
- 相机获取期间物理初态、机械臂保持不变；选择终点后固定外部位姿执行整任务。图片随机器人执行变化，并非静止图片策略。

## 信息权限

| 方法 | 查询点可用信息 | 明确不可用 |
| --- | --- | --- |
| Accel | 当前候选图下 8 个固定评分噪声的平均初态 Accel | 未查询候选分数、成功标签 |
| RGB 学习器 | 当前候选外部 RGB、腕部 RGB、已知任务 ID | 规范外部上下文、规范标记、候选 ID、规范相对位姿、仿真分割 |
| RGB＋Accel 学习器 | 上述信息＋当前候选 Accel 均值与标准差 | 同上 |
| 目录导航 | 候选之间的相对位姿 | 规范目标身份、未访问点图像与得分、闭环标签 |
| 已知标定参考 | 直接返回规范位姿 | 此权限不授予其余搜索方法 |

候选图片已有冻结 ResNet18 缓存，腕部特征仅提取历史 context 的后 512 维，前 512 维规范外部图不进入新学习器。规范视角可作为普通候选在访问后评分，但不能免费当成初始上下文。

## 学习与搜索

### 学习器具体训练流程

当前不是微调 VLA，也不是训练相机动作策略，而是监督训练一个候选视角评分器，再配合预先规定的图搜索。规范训练 VLA 和多视角训练 VLA 的成败标签分别训练评分器；每种各两类，共4个评分器。

1. 标签来自完整闭环矩阵：每个初态、每个相机候选，将32次完整任务成败取平均，得到成功率。16个开发初态×97候选共有1,552条带标签记录，但只有16个独立物理初态，不能当作1,552个独立场景。
2. 外部候选图、腕部图分别通过冻结的 ImageNet ResNet18 得到512维特征。没有使用 VLA 隐藏层、没有更新视觉编码器。仅开发数据拟合 PCA，将候选图降至8维、腕部图降至4维。
3. RGB版以候选图8维特征为基础；RGB＋Accel版再加入该候选8评分噪声的Accel均值、标准差，基础特征为10维。任务输入是8个已知任务的 one-hot ID，不是语言编码。
4. 拼接基础特征、基础特征×任务ID、基础特征×腕部特征，得到104维或130维输入。这些交互允许同一视觉特征在不同任务或腕部观察下有不同权重，但不是可任意表达复杂非线性关系的深网络。
5. 在每个开发初态内，分别减去该初态97候选的特征均值、成功率均值，再标准化特征并拟合带L2惩罚的线性最小二乘。它学习相对同初态候选平均水平的视角价值，不是直接拟合绝对任务难度。
6. 正则强度从1、10、100中选择。仅用初态0训练、1验证，再交换；每折重新拟合PCA、标准化及权重，按验证初态所选视角的平均完整成功率选超参数。最终使用开发初态0、1全部16个初态重拟合。当前规范训练模型两版均选10，多视角模型两版均选100。
7. 推理只需某一个已获取候选图、当前腕部图、任务ID和可选Accel；使用冻结PCA与标准化参数算加权分数。代码取负号使“分数越低越好”，输出不是校准成功率。推理不需要全候选均值：训练时减去的初态公共项不影响同初态内的候选排序。

选择器学习的是“给已观察的视角打分”。图搜索如何走、查询多少个点仍由固定算法决定，没有用强化学习学习移动策略。起点扰动的相机图只能在它作为实际查询点时提供，不额外提供规范相机上下文。

### 第九页指标规则对照

第九页仅比较保持扰动原位、单噪声最低Accel、8噪声平均最低Accel、最大外部可见性、平均Accel最低10个后按可见性选择，以及已知标定返回规范参考，不混入学习器。

“单噪声”指一次选择只使用一个Flow评分初噪，不是只计算一个去噪步；所有条件仍用原Accel_3定义。对已有8个评分种子分别选点，再平均8个被选终点的闭环成功率。不能挑表现最好的种子。8噪声平均条件则先对每个候选的8个Accel取均值，再选一个候选，两种计算顺序不同。

两者全查询97候选，但单次选择所需评分样本为97与776，本页不是等推理预算对照。可见性来自仿真实体分割，明确标为特权诊断参考，不能等同于真机RGB可直接获得的指标。原闭环矩阵、学习器权重及搜索结果不因本页调整改变。

### 有预算图搜索

学习器在每个开发初态内中心化特征和成功率标签，学习相对视角价值，不把任务整体难度当选点依据。图像 PCA 8 维、腕部 PCA 4 维；包含任务及腕部与候选特征的交互。增强版加入 Accel 均值和标准差。正则强度在 [1,10,100] 内用开发初态 0/1 互换两折选择；评价初态不进入 PCA、标准化、拟合或参数选择。

导航采用对称六近邻图，距离为平移/0.1m＋旋转/15°。这些参数和查询预算 [1,4,8,16,32] 在本轮拟合前写入运行协议；主预算16，不根据评价曲线调整。图不连通时直接报错，不暗加“回规范”边。

引导搜索从已访问的最好评分节点向未访问邻居展开；到该节点的路径仅穿过已访问节点。随机对照随机选已访问集合边界上的边，仍按相同评分选择最好终点。起点算一次查询，允许不改变终点，平分时保持先前最佳；不保证成功率永不下降。随机搜索8个重放种子，两个评分器共享随机导航种子。

每个查询是一个不同视角观测；Accel 方法对应8个评分样本，16查询对应128个评分样本的逻辑预算，但本次使用缓存，没有实际计时。重复经过已访问位置允许复用缓存，此假设依赖场景静止。

## 评价与统计

先完成全部搜索决策，再查终点的32次完整闭环成功率。每个初态内先对起点、随机重放求平均，再按任务—初态分层 bootstrap；不把16×32个起点当作512个独立物理初态。

同时保存全部预算成功率、相对原位增益、改善/变差/相同起点比例、选定终点、每次查询序列、目录路径累计米数和转角。随机方法的变差比例是对随机重放平均后与原位比较，不是单次随机运行的风险概率。

目录路径累计包含从最后查询点返回选定终点；并非无碰撞路径、真实动作轨迹、时间或能耗。现有目录跨度较大，有限查询数不能直接称为低运动成本。

## 尚未验证

1. 查询时新抽评分噪声的影响；当前每点固定8评分噪声均值。
2. 相机运动、等待及获取后观测变化；实际路径可达性、头部工作空间、实时成本。
3. 新执行噪声与未用于方法调整的数据上的独立确认；此前测试汇总已查看，全部新结果标为探索性。
4. 连续小扰动、未知候选位姿、RoboCasa 多场景和真机；腕部动作耦合需要独立协议。

下一步先冻结方法与运动/查询预算，做实际获取—选择—执行，并加入匹配等待、同预算随机、已知标定参考；再决定 RoboCasa 扩展。当前结果不是“真实部署已成立”的结论。
