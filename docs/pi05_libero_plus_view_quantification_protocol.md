# Pi0.5 × LIBERO-Plus 视角量化协议

## 研究问题

本实验只回答三个可检验问题：

1. **视角泛化缺口**：同一物理初态下，仅改变外部相机位姿，Pi0.5 的闭环任务成功率下降多少？
2. **固定视角优化价值**：在独立校准任务上选出的固定相机位姿，能在留出任务上追回多少成功率？
3. **主动感知价值**：执行前观察有限个候选视角并逐任务选视角，能否稳定优于最佳固定视角？

## 模型与执行设置

- 模型：官方 OpenPI `pi05_libero` checkpoint 的 PyTorch 转换件。
- 分词器：使用 Big Vision 官方 `paligemma_tokenizer.model`，并固定在共享缓存中避免运行时联网。
- Benchmark：LIBERO-Plus 的 `libero_spatial`、`libero_object`、`libero_goal`、`libero_10`。
- 动作执行：每次推理执行固定 `K=5` 步，与 OpenPI 官方 LIBERO 评测一致。
- 随机性：同一配对组共享物理初态、环境 seed 和 flow-noise seed；策略不读取相机真值。
- 语言指令：由基础任务名恢复为原始 LIBERO 指令，删除 LIBERO-Plus 文件名中的 `_view_…` 元数据。
- 观测控制：只改变第三方 `agentview` 相机；腕部相机、机器人状态和任务场景保持不变。
- 独立统计单位：`suite × 基础任务`，不把同一任务的不同视角或初始状态当成独立样本。

## 实验矩阵

### A. 视角泛化缺口

- 四套 benchmark 各 10 个不同基础任务，共 40 个任务。
- 每套覆盖 LIBERO-Plus 难度 1–5，每档 2 个任务。
- 每个任务使用 2 个配对初始状态。
- 每个初态分别执行 canonical 与官方相机扰动，共 `40 × 2 × 2 = 160` 条 episode。

主要量：

```text
视角泛化缺口 = canonical 成功率 - 官方扰动成功率
相机鲁棒率   = 官方扰动成功率 / canonical 成功率
```

同时按 suite、难度和扰动类型报告，使用任务级配对 bootstrap 95% CI。

仿真 renderer 额外输出关键物体实例分割，只用于事后诊断：

- 至少一个任务关键物体完全出画的比例；
- 关键物体低于 16 个可见像素、或触碰画面边缘的比例；
- 相对 canonical 的最小关键物体像素保留率；
- 关键物体仍清楚可见时的“纯视角泛化缺口”；
- 关键物体丢失清楚可见性后的缺口。

分割真值不会输入 Pi0.5，也不会输入主动视角选择器。

### B. 固定视角优化

全部 40 个基础任务在以下 6 个候选外部相机位姿上评测：

| 名称 | 中文含义 | 相对 canonical 的变化 |
|---|---|---|
| `canonical` | 标准视角 | 无 |
| `yaw_m30` | 水平向左环绕 30° | 方位角 -30° |
| `yaw_p30` | 水平向右环绕 30° | 方位角 +30° |
| `pitch_p15` | 相机抬高 15° | 俯仰角 +15° |
| `near_90` | 相机靠近 | 相机到观察中心距离为 90% |
| `far_110` | 相机远离 | 相机到观察中心距离为 110% |

每个任务和视角使用 2 个配对初始状态，共 `40 × 6 × 2 = 480` 条 episode。

基础任务按 suite 内 60%/40% 确定性划分为校准集和留出测试集。同一任务的两个初态不会跨集合。只在校准集选择：

- 一个全局固定视角；
- 每个 suite 一个固定视角。

最终只报告留出任务上的绝对成功率及相对 canonical 的百分点增益。

### C. 主动感知

主动感知采用“先观察、后执行”的最小协议：机器人状态不推进时查看 `B=1…6` 个候选视角，再选择一个视角完成整条闭环轨迹。

可部署选择器不读取任务成败标签：

- **动作不确定性选择器**：对每幅候选画面使用不同 flow-noise 采样，选择动作 chunk 分歧最小的视角；
- **图像质量选择器**：使用熵、边缘强度和过曝/欠曝比例构成的无监督图像分数。

另报告两个参照：

- **随机视角期望**：随机选择候选视角的期望成功率；
- **Oracle 上界**：事后为每个初态选择成功视角，只表示“移动传感器最多可能追回多少”，不是算法结果。

主动感知的关键比较是：

```text
主动选择增益 = 主动选择成功率 - 最佳固定视角成功率
可用视角上界 = Oracle 成功率 - 最佳固定视角成功率
```

若 Oracle 有明显增益而可部署选择器无增益，结论是“视角有价值，但当前置信度指标不足”，不能写成主动感知有效。

## 有效性与裁决

- 若 canonical baseline 明显低于官方模型应有水平，输出 `BASELINE_INVALID`，不解释视角结果。
- 视角缺口以任务级配对 95% CI 为准，同时报告绝对百分点，不能只报相对比例。
- 固定视角优化必须在留出任务上优于 canonical，校准集提升不算结论。
- 主动感知必须在相同候选视角和观察预算下优于最佳固定视角；只优于 canonical 不足以证明主动选择有用。
- Oracle 仅用于判断研究空间：若 Oracle 也没有增益，则该候选视角范围不存在可利用的主动感知空间。

## 解释边界

当前主动感知模拟外部相机可瞬时重定位，量化的是视觉信息价值。真实系统还需单独加入相机运动时间、机械可达性、遮挡和碰撞成本，因此本实验不是主动相机控制器的部署验证。
