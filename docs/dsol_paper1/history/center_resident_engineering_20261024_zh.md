# 跨块驻留与三机调度加速：CPU 工程回执

2026-10-24，北京时间。本轮按用户要求先做工程加速和时间估算，算法优化留待验证后讨论；没有启动正式实验、模型调用、EGL、训练或线上 W&B。旧科学清单、结果、源码副本和预算保持原样。

## 已接入

- 标准 queue → controller ledger → center 实时授权 → LIBERO adapter 链支持显式 `resident_workers`。一个槽可依次承接多个块并保留模型；每块仍独立预留预算、PREPARE/GO/ACK、逐调用 CHECK/CONTINUE、验证结果并结算。驻留不授予下一块许可。
- 所有权、epoch、节点、槽、绑定和许可身份保持固定。断联、未知启动结果和部分完成保留预留；不自动退款、重连或重发。驻留资源状态与任务完成回执分开，IDLE 仍占用槽；完成任务时不再把本进程仍存活误判为该任务在途。
- `resident_simulator` 可复用解释器和模块导入；每次轨迹仍新建环境、渲染器并执行原初始化。没有缓存物理状态或复用 EGL 上下文。失败关闭自身子进程并使会话失效。
- 通用资源描述支持每卡 1/2/3 worker；继续使用已有身份和显存峰值检查。补齐授权等待、模拟器启动/关闭/RPC 计时，保留原科学噪声与模型计算配置。
- 核心资源生命周期不导入模型或 benchmark；科学适配留在 LIBERO。新功能默认关闭、必须显式绑定；没有另建调度服务。

## 验证证据

- portable CPU 回归：488 passed，15 skipped，69.87 秒；跳过项未冒充已验证。
- 三机真实 SSH、72 个 CPU 槽、144 个模拟块全部完成；每台 24 个进程各执行两块。共 72 次复用，9,216 次逐项授权；结束后 72 个驻留记录均 CLOSED，全部模拟预算结算，dispatch=false。耗时 328.858 秒。零模型调用、零真实轨迹、零 EGL。
- 故障测试覆盖第二块 ACK/DONE 丢失、epoch 失效、空闲连接丢失、部分成功后停止，未知预算不退款也不重发；独立运行链原有重复控制器与显式恢复测试纳入 portable 回归。
- 真实 CPU 子进程/socket 测试确认解释器复用但初态重新建立；子进程死亡、调用方异常均禁止继续复用。面板假模型测试确认冷/热结果、轨迹数组和计数相同。这些不是 GPU 或物理仿真一致性证明。
- 结构、目录、项目导航、仓库检查和 diff 空白检查通过，详见持久目录 evidence。

持久证据：项目共享根 `runs/center-resident-engineering-20261024/`。`source/release.json` 标识本轮三机 CPU 候选；`recovery/` 保存当前补丁、源码和恢复步骤。没有提交或推送；`.env.example` 保持未暂存删除。

## 时间估算与启动顺序

旧三机 48-worker 批次完成 512 轨迹、17,473 调用，用时 878.196 秒，即 19.90 调用/秒。这是旧工作构成的参考，不是新版本吞吐测量。

## 正式启动前仍须完成

1. 候选运行链真实冷/热核验：按冻结输入比对初态、相机刷新、首帧、分数、动作和完整轨迹；CPU 替身不能替代。然后在同一科学构成下比较 48 与 72 worker 吞吐、显存峰值及长尾，达标才扩容。
2. 当前驻留科学适配仅注册原 `native_view_panel_v1`，完整40任务清单尚未接入该生产入口。模型缓存严格绑定整份配置，模拟器池最多两个配置；扩展到40任务时必须显式分配兼容配置组或增加经过测试的受控换组，不能直接把旧768面板扩表启动。通用72槽能力已经接入，不等于完整科学入口完成。
3. PPO采样/更新需要策略版本、全局批次和更新屏障；评测驻留机制不代表分布式训练已接入。算法优化和新训练等待本次验证之后的明确方案。
4. 新科学清单、预算、候选源码哈希、主机身份与期限另建绑定。5,278,656调用仍是待确认草案；旧许可、旧预算和 CPU_SIMULATION_ONLY 不可替代生产许可。
5. 当前源受中心授权约束；历史冻结副本仍可被同权限用户手动运行，不声称系统级全局隔离。正式派发前审计入口和运行进程，生产只用白名单冻结入口；旧副本仅作恢复证据，禁止自动重放。

本轮结论：CPU_ENGINEERING_VERIFIED，PRODUCTION_DISPATCH_OFF。工程候选已保存；真实一致性、GPU容量和新科学绑定未获本轮测试证明。
