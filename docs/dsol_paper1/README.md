# Paper 1：基于 Accel 的主动视角搜索

这是本论文唯一的当前状态入口，更新于 2026-10-22。历史文档中的“当前”“下一步”和运行时间只代表其撰写日期。

## 当前状态

- **研究主线**：冻结操作模型，以 Accel 决定已观察视角的选择，用 RL 减少搜索所需查询；从固定 97 点推进到连续 Δyaw/Δpitch＋STOP，再适配头部；动态候选保留为非学习对照。
- **历史结果保留**：固定97点的A8/B8共15,488条任务，以及连续v1的512回合训练和192条配对任务均已完成。连续v1成功数为不调整30/64、局部Accel30/64、PPO56/64；这是旧STOP探索项及旧初态采样下的四任务开发结果，不作为修正版或其他操作模型的新成绩。见[连续评测记录](protocols/continuous_evaluation_zh.md)。
- **修正版训练三组全部完成**：规范视角后训练模型：512回合/16更新，1,681查询/3,362去噪轨迹，约67.9分钟；多视角后训练模型：512回合/16更新，1,144查询/2,288去噪轨迹，约66.7分钟；原生模型：512回合/16更新，853查询/1,706去噪轨迹，约26.6分钟。均只导出最后一次更新，已核对512回合记录、预算及16份CPU部署控制。旧actor不覆盖，不按奖励择优。唯一算法配置为 `configs/dsol_paper1/search/continuous_search_stop_mixed_v2.json`。
- **原生模型对照与工程优化**：使用未做项目后训练的原始转换π0.5 LIBERO权重，经原生OpenPI预处理/解码，保留32维内部动作。GNU四状态捕获/返回24条、串行/四worker/跨批驻留36条均逐值通过；八worker冷/热两批精确准入48条也已通过，工程总计128条（含已否决的20条）。原生组8个驻留worker已正常完成并退出，W&B记录16次更新。不同模型与查询量不相同，不能将整轮时间之比全部归因于工程提速。不热改现有冻结源码。此前项目零步版本因quantile/mean-std解码失配被否决，20条工程调用、0次训练更新的记录保留，不当作科学反例。
- **匹配任务对照已准备，未启动**：每个操作模型192条真实配对任务（不调整、局部Accel、连续PPO），加32条规范视角任务；使用相同8初态、执行种子0–3及各任务时限。三组最终actor均已冻结，三组配对/规范视角清单均已通过CPU输入核验。旧规范视角成绩不能直接用来计算本轮扰动损失。后续还需资源准入、启动清单及首个完整三方法块检查。每条件上限12,864条去噪轨迹，三条件38,592条，不自动增加随机搜索。
- **解释边界**：分别训练搜索actor验证不同操作模型上的适用性，不证明零样本跨模型迁移；原生和项目模型保留各自有效解码及依赖栈，不是只改变后训练的单因素实验。任务已分析过，单个RL种子不证明训练稳定性。奖励及Accel改善均不等于任务成功率。
- **扩规模准备**：工程开发不必等评测结束；先补评测分块、阶段计时与持久提交，再做两机16collector的独立准入。规划主模型2048回合、64训练初态，及已有16任务/32留出初态的896条匹配任务；均为未启动草案，新增初态与预算仍待冻结。详见[训练与扩规模协议](protocols/continuous_training_zh.md#完整训练收尾与扩规模准备规划不启动)。
- **后续头部工作**：私有URDF已归档；当前仍是固定光心虚拟云台，相机标定与头部运动学尚未接入。

源码归属、并行边界和剩余技术债见[架构说明](../architecture/README.md)；运行计费与准入见[训练协议](protocols/continuous_training_zh.md)。私有运行、哈希、失败记录和看板入口统一在项目 `current/model-comparison`；不新增根目录实验文件夹。

## 结果能说明什么

| 证据 | 已支持 | 不能据此声称 |
| --- | --- | --- |
| A8/B8 本轮真实执行 | 相同本轮协议下不调整、局部 Accel、PPO 的配对比较 | 完整复现重启前实验；连续空间或真机泛化 |
| A 与旧回放对齐 | 1,536 条搜索选择/路径一致；统一种子和时限后均值接近 | 逐条执行一致：三方法仍有 327/12,288 条成败不同 |
| 奶酪初态2、候选46 | 旧/新差异集中于种子0/5；本轮25个选中该视角的搜索结果重复执行一致 | 根因已修复、已找到首次动作差异。旧记录缺逐步数组 |
| 连续渲染准入 | 固定光心虚拟转动的位姿、输入及返回一致 | 新 actor 已有效、实际头部相机已标定 |

旧执行器是重启前固定视角矩阵的运行程序；新执行器是接入 RL 搜索的运行程序。
操作模型相同不等于执行链已逐条复现。旧结果保留为对应协议的历史证据，本轮结果单独报告；不能混合两轮结果或把未解决差异写成已修复。
